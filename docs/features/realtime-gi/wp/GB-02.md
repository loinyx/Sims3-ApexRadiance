### WP2: the patch

`AddGBufferPs` only inserts instructions; no game token changes.

- **Albedo** (`oC1.rgb`): the result of the single `texld` on the table's albedo sampler, copied to a free temp right
  after the read. A read inside a branch (60 Phong shaders read `DiffuseMap` only on their lit path) starts the temp at
  "unknown" and fills it in the branch, so the other paths write id 255.
- **Material id** (`oC1.a`): id / 255. Without an albedo: `(0, 0, 0, 1)`, the reserved id 255.
- **Normal** (`oC2.rg`): the coordinate of the single `texld` on the diffuse light probe, copied just before the read
  with the read's own swizzle, then octahedral (`p = n / (|x| + |y| + |z|)`, lower half folded), 10 + 10 bits.
  10 instructions; no normalise is needed before the projection.
- **Roughness** (`oC2.b`): a constant per material id. 0 = "no normal written, use the geometric one".
- **Motion class** (`oC2.a`): class / 3. 3 for Sim, foliage and water techniques.
- Registers: 3 temps, 2 constants. Refused: not `ps_3_0`, subroutines or `ret`, relative constants, no free
  register, another output than `oC0` already written.
- **Merged copy:** the binder applies `AddDither`, then `AddGBufferPs`, on the same tokens, and looks the row up by
  the hash of the game's bytes. A shader without a row gets the unknown values (no albedo, no normal, class 3).
- SimSkin and TerrainHigh rows carry no albedo sampler on purpose (composited albedo; family rules are WP10).
  TerrainHigh has 392 shaders with a single `colorMap` read that the generator would otherwise accept.

### WP3: targets, binding, masks

- **Targets:** `A8R8G8B8` and `A2B10G10R10`, back-buffer size, `D3DPOOL_DEFAULT`, released before Reset. Made at the
  scene boundary, so the first frame has none. Off with `[GBuffer] Targets off: <reason>` when the device has fewer
  than 3 simultaneous targets, a format is not a render target, the back buffer is multisampled, or the
  High-precision scene is active and the device lacks independent bit depths (its 16-bit target is 64 bits a pixel).
- **Bind:** at the first scene draw into the back buffer (depth test on and used) the targets are cleared to 0 once a
  frame (`ColorFill`) and bound as render targets 1 and 2. They are unbound before any `SetRenderTarget(0, other)`,
  at the scene boundary before the first effect, at Present and before Reset. A caller that binds its own target 1
  or 2 takes the slot.
- **With the High-precision scene:** the per-draw grain is off there, so the binder binds the copies for the
  G-buffer alone with the grain amount 0. The resolve already unbinds and restores targets 1 to 3 around its draw.
- **Write masks:** `COLORWRITEENABLE1` / `2` are `0xF` only for an opaque draw of a copy with the outputs; every
  other back-buffer draw the binder sees while bound sets them to 0 (blended draws of a copy, `ps_2_x` copies,
  refused shaders, fixed function, depth-off and UI-style passes). The state is tracked, so a run of equal draws
  costs no call. The blend test is the device state at the draw, not a render-state hook: the binder reads it for
  every copy already. Ambient Occlusion's Sim receiver replay closes the masks before its own draw.
- **Views** (`view`): 2 albedo (unknown = mid grey), 3 normal as `0.5 + 0.5 n` (no normal written = dark grey),
  4 material id (one colour per id, 255 magenta), 5 motion class (grey, green, yellow, red), 6 scene pixels with depth
  that no copy wrote (red). Black in 2 to 5 = nothing written.
- **Counters,** every 10 s: `[GBuffer] Scene: frames= patched= unknown= blended= masked= binds= unbinds=
  bindFailed= maskToggles= view=`. `patched` / `unknown`: opaque draws that wrote with a table row / with the unknown
  values; `masked`: other draws while bound.

## Smoke job (in-game runner, Apex + bridge)

```
./tools/ingame_runner/run.ps1 -GameBin '<Game\Bin>' -Job tools/ingame_runner/jobs/gbuffer-motion-smoke.json -Asi Release\ApexRadiance.asi -AB
```

- Six loads, one view each (`order`: motion, albedo, normal, material, class, unwritten); without `-AB` only the
  motion view. Each: paused 1 min, one F8 picture, then a 60 s camera pan.
- **Pass:** no crash and, per load, the `Caps`, `Targets`, `Motion` and `On: ... view=<name>` lines and a `Scene`
  line with `patched` above 0 and `bindFailed=0`. **Fail:** `Could not create`, `Shaders unavailable`,
  `Caps: GetDeviceCaps failed`, `Targets off`, or `bindFailed` above 0.
- **Read after the run:** objects in their texture colour (albedo), colours that follow the surface (normal), flat
  colours per object (material, class), the UI absent from every view, no trails behind glass or particles, and how
  much of view 6 is red. The `Scene` line gives patched : unknown : masked draws.

## Open issues

- The smoke job has not run (no game launch in this package).
- **Coverage is partial by design:** only the 5 families have rows, and `ps_2_x` draws write nothing (WP5). Walls and
  most floors therefore show black in views 2 to 5 and red in view 6.
- **Shaders replaced by Night Lighting** have other bytes than the game's, so they find no row and write the unknown
  values. Fix when it shows: key the lookup by the hash of the game's shader the replacement was made from.
- A masked draw in front of a written pixel leaves that pixel's older values (research 14 §3.5): view 6 cannot show
  it. The depth-check channel is WP9.
- Draws that do not pass the binder's hooks while the targets are bound (`DrawPrimitiveUP` from the game in the
  middle of the scene, a module that draws through the unhooked device functions) use the mask of the draw before.
  Ambient Occlusion's replay is handled; others would show as wrong colours over whole surfaces in the views.
- The table's material ids and roughness values are first guesses from technique names.
- The motion class of a shader shared by a mover and a static technique is 3.
