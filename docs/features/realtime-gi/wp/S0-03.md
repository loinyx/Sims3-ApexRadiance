## Verdict

- **Layout exists at class 0 before the first solve** (verified, Steam 1.67.2). The room rebuild `0x006A2740` →
  `0x006A1DE0` → wall update `0x006AC000` → `0x006AB0E0` packs every wall's strip in the class 0, 1 and 2 atlases
  (one shelf packer per story and class, `manager+0x160 + class × 0x40 + 0x1C`), then sets state 1 and class 0.
- **Vertex uv exists at class 0 before the first solve** (verified). The wall uv source `0x006A5600` reads the shown
  class `room+0x100`; a never-solved room (4) is mapped to class 0 by `0x006A8C20`.
- **Not stable across classes** (verified): each class has its own atlas (256x128, 512x256, 1024x512), strip sizes
  scale with texels a tile (1, 2, 4) and strips are packed independently. **Stable while the room stays at class 0**
  (verified by the code path; the cap keeps shown = 0), until a wall edit rebuilds the room or the packer resets.
- **Texel → position for walls is a closed form** of the wall object (verified): `wall+0x110 + wall+0xF0 × (u + 0.5) / W
  + up × 3 × v / H`, normal `wall+0x150`, `X = x0 + u`, `Y = y0 + H − 1 − v`. No solve and no rasterisation are needed
  for walls at any copy scale.
- **Scaled copies have no strip seam** (verified arithmetic): the vertex uv spans texel centres, so a copy `s ≥ 1`
  times larger is safe if it fills each strip's whole area from the same wall.
- **Floors:** whole tiles = grid origin `tile+0x40/+0x44` × texels a tile (verified); split and diagonal tiles not traced
  (open).

## Fallback

Capture the class-0 solve's own samples (`0x01158AC8`, 0x30 bytes each: position, normal, X, Y) at the batch-solve
calls `level_light_share` already hooks: exact for every texel the game writes (walls, floors incl. split tiles,
ceilings, objects). Interpolate inside a strip or tile for scale above 1. Last resort: scale 1.
