## Start-line pattern [verified by selftest on matching and near-miss lines]

`\[RealtimeGI\] On: lots=\d+ cap=(off|class0|hold) scale=[124] indirect=(off|bounce1|multiBounce) backend=(auto|serverRays|serverCompute|d3d9)`

Built from design.md §6; if the real line differs (for example a backend name), change the pattern in the jobs and
the selftest together. `selftest.ps1` reads the pattern from the smoke job and rejects `Off:`, a missing backend, a
non-number, an unknown cap or scale, a longer tag and another feature's line. The off variant fails on the same line
(a selftest rule for every job).

## Findings

- The runner copies `ApexRadiance_Hitches.txt` into each load folder, together with the LOG and Crash files, when its
  write time is not older than the load's start (`run.ps1`, after the game exits) [verified, reading `run.ps1`]. The
  profile job's counter block is therefore in the load folder; it is also in the restore list.
- The runner's Frida frame profiler (`-Profiler Frames|Both`) hooks `0x00EC9F00`, as does the Frame Profiler; the
  profile jobs must run with `-Profiler None` (the default). Their `profile` step is a plain time window then.
- `realtime-gi-look` views: three are from `night-lot-switch-pan`, one is the `gym-entrance` bookmark (its save is not
  recorded; check it); they are not room-across-a-wall views. S1-G1 should add real room bookmarks.
- `realtime-gi-rooms` lacks wall-edit and door steps (not in the agent); it covers toggle and move with `lamp_edit` and
  `lamp_drag` near outdoor points of Sunset Valley [inferred: they hit a lamp there; not run].
