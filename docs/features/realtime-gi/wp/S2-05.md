## Scope

The brief asked for per-family pixel shader patches (walls, floors, objects, Sims) that find the atlas texel from the
pixel's world position. What was built and why the rest is not:

| Surface | State | Why |
|---|---|---|
| Floors and ceilings, ps_3_0, Smooth light maps on | Read the atlas | The room-map copies already pass through `DrawWithRoomMap`, and the floor vertex shader already sends the lot position (TEXCOORD4) that the arch copies read |
| Walls | Not covered [O] | No lot position reaches the wall pixel shader; needs a vertex shader output (the wall matrices) first |
| Objects, Sims | Not covered [O] | They bind no room map; design D6 feeds Sims through the rig |
| ps_2_0 room-lit shaders (66 in the precomp) | Not covered | Can reach no constant past c31 (the GI rows are c215-c216) and are slot-full (design D1) |
| Smooth light maps off | Not covered [O] | Without the copies there is no draw to swap |

## What it does

**Grid (`GiIndirect::Build`).** The atlas keeps texels where the allocator put them, so a shader cannot find a texel
from its place. The grid copies the floor and ceiling texels to places: one layer for each (story, floor or ceiling),
covering the whole lot at the scene's density (2 texels a metre), with an empty row between layers so a bilinear read
never reaches the next layer. Built on the CPU when the scene changes; filled on the GPU by `Scatter` (one point draw,
atlas pixel to grid pixel) after each compose or a change of the ready tiles. Texel (gx, gz) of a layer is the texel
whose cell is floor(x d), floor(z d) in lot space.

**Ready mask.** Grid alpha is 1 for texels whose tile has every on lamp of the lot that may reach it (the lamp's
reach box, `GiSched::Around`) with a layer; 0 while a lamp still waits, and 0 where no texel is (outside rooms). The
copy keeps the game's ambient where alpha is 0.

**Patch (`PatchRoomMapGi`, ps_3_0 only).** On the room-lit pattern `texld rL, TEXCOORD1, sM` /
`mad rD.xyz, rL.w, cA, rL` (cA = the room's ambient), seven instructions go before the `mad`:
`G = grid(TEXCOORD4.xy x c215.xy + c215.zw)`; `rgb' = rL.rgb x k.y + G.rgb x G.a x k.x`;
`alpha' = rL.a x (k.z - G.a x k.w)`, with k = c216; the `mad` then reads rgb' and alpha'. Refused (bytes unchanged)
on ps_2_x, flow control before the `mad`, more than one match, no free temp or sampler, or a constant at c215 or above.

| Mode (`indirect`) | k | Result |
|---|---|---|
| `off` | (copy not used) | The game's copies, byte for byte |
| `atlas` | (1, 1, 1, night) | Night: lamp light + atlas, the ready share of the room ambient replaced. Day: the atlas adds to the ambient |
| `atlasDebug` (developer builds) | (1, 0, 0, 0) | The atlas alone |

**Which map is which.** A draw's bound room map is matched to a story and kind through each story's room 0 of the GI
lot (manager +0x88 the story; texture set +4, class x 64 + 0xC + index x 4, index 1 floor, 2 ceiling; wrapper +0x30 the
texture), read under SEH, cached per map.

**Device reset.** `RenderCallbacks::preReset` releases the grid, the layers, the compose and scatter buffers and the
scene, and resets the lot so the next update loads it again.

## Findings

- [I] TEXCOORD4 lot space (the floor vertex shader's) is the lot space of `KeptLot` / the scene's texel keys. Check in
  game: the debug view must line up with the room outlines.
- [I] The ceiling map of story s holds the ceilings whose texels the scene files under story s.
- [I] A lamp's reach box is a safe ready rule (a texel outside it gets nothing from that lamp).
- [I] Bilinear reads leak up to a quarter metre across a wall between two rooms (one texel at density 2).
- [O] Gain 1: the atlas colour is not calibrated against the game's law (S6-01).
- [O] The day rule (atlas adds) may double count with the game's daylight ambient.
