# S0-09: rig facts for the rig write

Status: done (static reading, Steam 1.67). Branch `gi/s0-09`.
Details and addresses: [light-objects-and-rigs.md, "Rig write facts"](../../../engine/light-objects-and-rigs.md#rig-write-facts-real-time-gi-s0-09-static-reading-of-steam-167).

## Findings

- **Directional maps feed Sims on the CPU: no** (verified). The room-mode gather `0x006BBDE0` -> `0x006BB2F0` reads the
  room's lamp list, an occlusion query and a tile colour it passes on but never uses. Sims are rig-only, as the shader
  bindings of 02 §4.1 said; `gpu-room-lamps.md`'s "objects and Sims" is wrong for Sims.
- **Room rigs already drop lamps hidden by the room's occluders** (verified): each kept lamp gets a segment query
  `0x0069D4C0` from the rig centre; a hit pops it from the gather list. Occluders are probably the room's walls (inferred).
  The rig write's "Sim behind a wall gets no lamp" (S3-03) matches the game's own room behaviour.
- **Slots 1-3 and the four vertex-light slots are writable** (verified): the binder `0x006B8B30` binds pointers to rig
  memory; only a gather rewrites them. Vertex lights are directions, not positions. Exceptions: room rigs have no sun
  (slot 0 is a lamp); the fill light sits in slot 1 of room rigs; for mode-0 rigs a per-draw clamp
  `min(c x (1+f), 0.5 x (1+f))` applies to slot colours when the lot `+0x3B8` object answers true for the room
  (verified code, unknown how often it is true).
- **Where to write** (verified order): on return of `0x006BBDE0` and `0x006BBBA0`. Every re-gather goes through them
  (`0x006BBF90`, `0x006BBFE0`). The write lands after the cap (single call site `0x006BA564`, byte `[0x01158D5D]`), the
  fill light and the `[0x011D0C50]` room scale, so Apex needs its own ceiling. Apex's existing `RoomGatherThunk` is too
  early (it runs before the distribute and sees the gather list).
- `[0x01158D30]` set (a render setting `== 2`, which one is inferred only) switches to another distribute and bind path
  using rig `+0x110..+0x13F`; a rig write must skip that case or fill that block too.
