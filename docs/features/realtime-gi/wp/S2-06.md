## Findings so far

- [V, precomp Steam 1.67.2] The only ps_3_0 InteriorWall vertex shader is blob 8507 (pixel shaders 8508-8515). It reads
  `dcl_position v0`, `dcl_normal v1`; object position r0 = (v0.x/256, height lerp, v0.z/256, 1); world position is the
  triple `dp4 r4.x/y/z, r0, c4/c5/c6`; normal decode `mad r3.xyz, -c10.w, v1, -c10.z` (2 v1 - 1); outputs o0-o7
  (TEXCOORD0-6), so **TEXCOORD7 is free** (vs_3_0: 12 outputs). Its pixel shaders read TEXCOORD4 = the **world normal**,
  not a lot position: S2-05's `PatchRoomMapGi` (TEXCOORD4) must never run on a wall draw (S2-05 gates on `band[1] > 60000`,
  keep that). Highest VS constant read: c11, no relative addressing, so c242-c247 are free for this shader.
- [V] Floor VS (blob 1639): lot x, z = v0.xy / 2; y = v0.z/256 + v0.w + c11.x - 128 (a per-draw constant in y).
- [V, code] **Probable S2-05 bug:** `MapLayerRead` (realtime_gi.cpp) takes texture-set index 1 = floor, 2 = ceiling.
  `RtOutdoorLamps::kSetIdx = {3, 0, 1, 2}` (wall, floor, ceiling, objects) and `OutdoorDelta::kSlotIdx` say floor 0,
  ceiling 1, wall 3. **Fixed** on `gi/s2-05-slots`: `GiIndirect::KindOfSetIndex` (0 floor, 1 ceiling, 2 objects and 3
  wall none) used by `MapLayerRead`; `tools/gi_indirect_test` checks the order [V offline; I in game until the debug view
  lines up]. Before the fix ceiling maps took the floor layer and object maps the ceiling layer.
- [V, docs/features/night-lighting/unlit-rooms.md, unlit_rooms.cpp] Room ambient `room+0x110` = lamp part + base colour
  C (C = slot colour x `[0x011D0B88]`). With Rooms at Night: lamp' + C (additive, `UnlitRooms::LampAmbient` = amb - C).
  Vanilla: lamp' + shortfall towards C. So the lamp share L = max(0, cA - C) per channel.
- [V] scene_dither's jitter/dither copies wrap Apex's re-issued draws (`ObserveReissuedDraws`), so a VS copy bound by
  lot_light_bridge still gets TAA jitter; the copy must not touch oPos (it doesn't, see below).

## Design (to build)

1. **Wall grid** (`GiIndirect::Build`, gi_indirect.h): axis-aligned wall texels (codes 0, 2, 4, 6; block = code / 2)
   go in a region right of the floor layers: 5 blocks side by side (+x, +z, -x, -z, block 4 always empty), each
   `A + 1` columns (A = along cells = max(lotW, lotH) x d, one gutter); rows = slice `li = round(line coord)` x
   (Y + 1) + floor((y - yO) d), yO = lowest wall texel y - 0.5 / d. Diagonal walls: no consumer [O]. Lines whose y0 x d is
   not whole read off-centre [I]. Width/height <= 4096 or no walls.
2. **Wall VS copy** (`ShaderPatches::PatchWallGiVs`, vs_3_0 only): find the world triple (dp4 rW.xyz, rP, cK..cK+2) and
   the normal decode (an instruction reading only dcl_normal and constants); after the triple: lot P = rows c245-c247
   (worldToLot as dp4 rows) on (rW, 1); lot N = rows on (cK dp3 decode); s = |N.x| >= |N.z|; line/along by lrp;
   li = floor(line + 0.5); block = 1 - s + 2 (facing < 0), = 4 when max(min(|Nx|,|Nz|), |Ny|) > 0.3 (caps, diagonals);
   u = along c242.x + block c242.z + c243.x; v = li c242.w + y c242.y + c243.y; write `dcl_texcoord7 oN.xy`.
   c242 = (d/W, d/H, (A+1)/W, (Y+1)/H), c243 = (x0/W, -yO d/H), def c244 = (0.5, 0.3, 4, 1). About 31 instructions.
   Refuse: not vs_3_0, flow control, no single triple, no normal, TEXCOORD7 used, a constant >= 242 or relative.
3. **PS patch** (`PatchRoomMapGi(t, out, texcoord)`; walls texcoord 7 with c215 = (1, 1, 0, 0)), new sequence before
   the game's `mad rD.xyz, rL.w, cA, rL` (18 instructions, 2 texld, 3 temps, 2 samplers):
   uv; point-read flags; p = uv x size (c218 = W, H, 1/W, 1/H); o = frc(p) - 0.5 clamped to 0 on each side whose flag is
   set (def c219 = (0.5, -0.5, 0, 0)); uv' = (floor(p) + 0.5 + o) / size; G = grid (premultiplied rgb, a);
   rgb' = rL.rgb k.y + G.rgb k.x - rL.a G.a L (c217 = lamp share L); alpha' = rL.a k.z. k = (1, 1, 1, 0) atlas,
   (1, 0, 0, 0) debug with L = 0. Store `out.ambientConst` (the mad's c) and `out.flagSampler`.
4. **Bleed** (item 3): flags texture, A8R8G8B8 MANAGED, grid size, built on the CPU with the grid: r/g/b/a = do not blend
   toward -u/+u/-v/+v. Set when the neighbour cell is empty, of another story, or the segment between the two texel
   places crosses a wall edge of the texel's story (`Story::edges`, lot space). Covers floors (wall between rooms),
   walls along a line (a perpendicular wall at a junction) and walls between stories.
5. **Premultiply**: `kScatterShader` returns rgb x alpha; `FillCpu` the same; `Apply` drops the `G.rgb x G.a`.
6. **Day/night** (item 2): replace only the lamp share: L = max(0, cA - C) with C from a new
   `UnlitRooms::BaseColour(room, rgb)` (render thread: `SlotOfRoom` + `g_target[slot]` x `[0x011D0B88]`, room = a GI
   story's room 0); without it L = cA x night (S2-05's rule). Read cA per draw with `GetPixelShaderConstantF`.
7. **Wiring**: `IndirectBind` gains flags texture, size row, lamp share, wall VS rows; `IndirectFor(map, ambient, night,
   out)`; `MapLayer` kinds floor 0 / ceiling 1 / wall 3 (fix above); `DrawWithRoomMap` wall branch (`band[1] <= 60000`):
   VS copy cache by game VS, set c242-c247 (save/restore), `SetVs` copy, PS copy cache `g_roomMapGiWallPs`, bind grid
   (linear) + flags (point) with `WallMaskBind`, restore. Counter `WallDraws`; add `wallDraws=` to the counters line and
   `gi-indirect-smoke.json`. Release flags texture on reset / shutdown.
8. **Objects / Sims (D6, plan only)**: write into S2-05.md handoff: rig write (design D6, research 02 option A): per model
   the irradiance at its centre from a CPU copy of the grid (batched read-back every few frames or the server's point
   query), into the 4 vertex-light slots; objects with a room map stay on the floor/wall path.
