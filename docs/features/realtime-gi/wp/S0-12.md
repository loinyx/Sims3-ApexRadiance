# S0-12: reflectance source for bounce light

Status: done (static reading, Steam 1.67). Branch `gi/s0-12`.
Details and addresses: [room-light-maps.md, "Reflectance source"](../../../engine/room-light-maps.md#reflectance-source-real-time-gi-s0-12-static-reading-of-steam-167).

## Findings

- **Per-room floor colour exists and is safe to read** (verified). Each floor quarter-tile holds an ARGB8 colour (tile
  section `+0x80`). Floor painting writes the pattern's catalog colour there (ProductPattern `+0xB8`, default `0xE0E0E0`),
  pulled 30 % toward grey. A bare tile holds white. `0x0069FF20` averages section 0 over the room's tiles. The mean is
  only stored multiplied into the specular probe multipliers `+0x140` / `+0x130`, so Apex should run the same tile loop
  itself: plain memory, changed only by floor edits.
- **Walls and furniture have no colour in the lighting data** (verified for the lighting code). Keep `kIndoorReflection`
  for them, or tint it by the floor hue. A wall pattern's catalog colour should be reachable through the same class, but
  where a wall keeps its pattern key was not traced (inferred).
- **The game already fetches the floor colour under each room rig** (`0x006A1660` from the gather `0x006BBDE0`) and drops it.
  This is a ready point query for a floor-bounce tint on Sims (verified call, unused result).
- Values are 8-bit and authored per pattern. Linearise before use (inferred). Whether Create-a-Style recolours change the
  value is unknown.

## S0-09 open points answered

- **Room manager `+0x3B8`** (verified) is the LotLightingManager interface. Its vfunc `+0x34` is true only for rooms in
  the strobe delay map (script `World_SetRoomStrobeDelay`, strobe lights), with `f` the current strobe value. The binder
  clamp is the strobe flash, so it applies only in rooms with a strobe light. A rig write can skip those rooms or apply the
  same clamp. Vfunc `+0x30` is "room is black-lit".
- **`[0x01158D30]`** (verified code) is set when the render config's shader tier is 2, the minspec shader path. Tier 2 is
  chosen when `RenderForceMinspecShaders` is set, and GraphicsRules.sgr sets it only for Advanced Rendering Off. It is 0
  on supported cards with Advanced Rendering on, so the alternative distribute path matters only for that option.
