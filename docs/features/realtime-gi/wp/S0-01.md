# S0-01: CPU reference of the indirect data model

- Status: done (synthetic stories); the captured-lot run is open (no capture on the work machine)
- Branch: `gi/s0-01`
- Deliverable: `tools/rt_lamps_test/gi_reference.h` (the reference), `GiLayersCheck` in `tools/rt_lamps_test/check.cpp`,
  `run.ps1 -Gi` (GI cases only, no device; `-Worlds` adds captured lots to the compose check)

## What the reference is

- One layer a lamp, unit colour, 1 texel a floor tile and story ([design §3.3](../design.md#33-data-model-light-is-linear)).
- Patches: floor tiles (the texels), roofed tiles' ceilings, wall pieces about 1 m x 1 m on both faces, opening holes left
  out; each point 5 cm off its surface.
- Links: point-to-patch form factor `A cos cos / (pi d² + A)`, one ray of visibility against the occluder proxy
  (`RtLampProxy::Mesh`), pairs up to 12 m apart. Geometry only: built once, shared by every lamp.
- Direct: the GPU lamp law (`RtLampModel::Add`) times the lamp ball's share (16 disc rays, 0.15 m).
- Bounces: 16 Jacobi steps of `E = d + F (albedo E)`, albedo 0.5 for every surface (S0-12 replaces it).
- Compose: `sum(on x colour x layer)`. Upsample: bilinear over the four nearest tile centres of the story, a centre
  dropped when the proxy blocks its segment to the point, weights renormalised.

## Findings

- Verified: `RtLampProxy::Clear` is not watertight. A segment through the shared edge of two wall quads, as tile centre
  to tile centre crosses a wall exactly at a tile corner, missed both triangles (also by the brute-force `FirstHit`) and
  linked the closed rooms' floors: every texel of the other rooms lit. The reference tests a second segment shifted
  off the grid lines (`GiRef::Seen`). Ray back ends (R-02) need a watertight test or the same guard; the GPU side
  (S2-02, S0-06) needs a leak case with points exactly on tile centres.
- Verified: `RtLampProxy::Visibility` skips 1 cm at both ends of the disc point to receiver segment. A lamp 5 cm under a
  ceiling has disc points within 1 cm of it, and the upstairs ceiling got direct light through the ceiling. The
  reference uses its own disc walk with no skip at the emitter end (`GiRef::LampShare`). The shipped direct path
  (`rt_lamp_proxy.h`, used by the existing checks) was not changed; whether the GPU direct shadows show the same leak is
  open.
- Inferred: a layer costs 36-78 ms on the CPU for 800-850 patches and about 80 k links; the links (0.5-2 s a scene) are
  the bulk and are shared by all lamps. A 64 x 64 lot with four stories is about 20 times the patches: the CPU reference
  is for checking, not for the game. S2-05 measures this on a big lot.
- Also fixed to make the harness build: `run.ps1` lacked the `framework` include path, and `rt_lamp_gpu.cpp` now calls
  `ExtraHooks::MarkVertexInput` / `RestoreVertexInput`; `check.cpp` defines both as no-ops (no game hooks offline).
  The rest of `check.cpp` was compiled but its device checks were not run in this package.
