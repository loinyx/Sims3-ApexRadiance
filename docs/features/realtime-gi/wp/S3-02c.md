# S3-02c: fence, stair and window draws from the lamp index cells

**Status:** done offline, no game run. The bridge draws fences, stairs and window frames from the lamp index cells under
`[patches.RealtimeGI] lampIndex 2` and compares their per-draw picks with the cells under `lampIndex 1`; the cell slices
stop on a per-cell clock check; the offline check times a whole sliced build with a heavier wall test; `lamp-index-smoke`
reads the fence and window counters back. Branch `gi/s3-02c` (from `gi/s3-02b`), commit "lighting: fence and window
draws from the lamp index cells".

Marks: **[V]** verified by the offline check (`tools/lamp_index_test`, Steam 1.67.2 precomp), the runner selftest or the
builds, **[I]** inferred, **[O]** open.

## Findings

- **[V]** Offline check, full run with the precomp: 70 checks, 0 failures. Fences and stairs: 1,231 hosts take the index copy under
  both laws with and without the floor-tile shadows, native D3D9 accepts all, 230 drawn equal to the per-draw copy within
  1 LSB. Window frames: 14 hosts, every index copy taken under both laws, drawn equal within 1 LSB. Objects unchanged
  (814 of 814, 624 drawn equal).
- **[V]** Developer and public builds (Release x86) succeed with no new warning. Runner selftest: 530 checks, 0 failures.
- **[V]** Slice time with the wall test (model pick, 150 lamps, 4,096 cells, the full run on a busy machine):

  | Wall segments in the model's test | CPU a cell | Whole build CPU | Frames at 1 ms | Thread CPU a frame: median / p95 / worst |
  |---|---|---|---|---|
  | 14 | 15 us | 60 ms | 81 | 0.84 / 1.01 / 1.02 ms |
  | 200 | 51 us | 208 ms | 220 | 1.01 / 1.05 / 1.06 ms |
  | 800 | 214 us | 876 ms | 884 | 1.04 / 1.20 / 1.31 ms |

  The 1 ms slice holds in the thread's own CPU time: a frame overshoots by its last cell. The clock time a frame went to
  4 to 28 ms in single frames when the machine was busy (the thread switched out), which a game frame suffers the same way.
- **[I]** The game's wall test (`LevelLightShare::LampVisibility`: `WallPass` and the slab grid) is not a scan of every
  wall, so the 800-segment row is an upper estimate. A whole rebuild (first build, walls or law changed, table full)
  then takes about 60 to 900 frames, 1 to 15 s at 60 fps, while the per-draw pick draws the stale cells. The in-game
  line `Lamp index: cells built (...)` gives the real figure.
- **[I]** Fences under the index copy take each pixel's own cell instead of the group's one lamp list and the per-piece
  runs; the cell visibility is a loose object's. The ground weight is one value a draw, from the cell at the group's
  centre (the per-draw path weighs it per run). Window frames take the cones per pixel and leave out the lamps shining
  out of a house, as the index copy was built (S3-02b).
- **[I]** The window's walls copy (`basis_wall_filter`) is only replaced by an index copy whose walls inputs (size and
  floor samplers) match; that variant has no offline proof (the check covers the copy without walls).
