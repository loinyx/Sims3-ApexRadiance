# S0-05: compile cost of the shader snippets

**Status:** done. Branch `gi/s0-05`, commit "tools: real-time GI shader cost table".

Deliverable: [tools/realtime_gi_shader_cost](../../../../tools/realtime_gi_shader_cost/README.md); the full table is
its [results.md](../../../../tools/realtime_gi_shader_cost/results.md). All numbers below are **verified** by real
`ps_3_0` compiles (fxc 10.1, `/O3`) unless tagged otherwise.

## Findings

| Snippet | Slots measured | Note 02 section 2 estimate | Temporaries |
|---|---|---|---|
| One lamp from constants (vector, distance, window, N.L) | 18 | ~9 | 3 |
| Its cone | +4 | ~4 | +0 |
| Its shadow, cube face pick and 1 compare | +27 | ~18 | 6 |
| 4 taps instead of 1 (averaged / bilinear weights) | +28 / +31 | +~12 | 6 / 7 |
| Index cell read and 4 lamps x 2 `texldl`, no light | 45 | 12-16 | 5 |
| Index cells, 4 lamps: no shadow / 1 compare / 4 taps / cone + 4 taps | 92 / 197 / 316 / 345 | - | 6 / 11 / 13 / 15 |
| Index cells, cone + 4 taps, `rep` loop over 8 or 16 lamps | 110 for any count | - | 16 |
| Compose, 16 layers: plain bilinear / wall-aware | 68 / 408 | - | 5 / 11 |
| Plan sphere trace, 8 / 16 steps unrolled; 16 steps looped | 105 / 201; 31 | - | 5; 4 |
| Gather, 16 virtual lights: no visibility / room table | 321 / 419 | - | 12 / 14 |
| Gather, 16 lights x 8-step trace: unrolled / loops | 2099 / 74 | - | 16 / 11 |

1. **The hand counts of note 02 were low by 1.5 to 2.5 times.** A shadowed lamp is 45 slots (1 compare) or 76
   (4 taps, bilinear), not 31 or 43. A `texldl` is 2 slots, and keeping four taps inside a face costs a clamp.
2. **Unrolled, lamp counts are tight.** 4 lamps from index cells with 4-tap shadows add 316-345 slots: this fits the
   room-lit shaders (59-170 slots) and SimSkin (158) but not the roof shader (343). 8 unrolled lamps fit only with
   1-compare shadows and only on the 59-slot host.
3. **A `rep` loop removes the limit, and only the index-cell route can use it.** Constants cannot be indexed in a
   `ps_3_0` loop, table texels can: with one index texel a lamp, the whole block is 110 slots for any lamp count
   (708 instructions run for 8 lamps, 1388 for 16) and fits every host including the roof. This is the shape to
   build in S3-02.
4. **Temporaries are no limit:** at most 16 of 32 in any snippet. Samplers: 1 atlas for the lamp block; 3-4 for the
   passes. Constants: at most 20 of 224. Inputs: position and normal only.
5. **Compose fits in one pass,** wall-aware with 16 layers at 408 slots and 140 reads. Plain bilinear is 68 slots.
6. **The gather with a plan trace must be looped.** Unrolled it is over 512 slots even with 4 virtual lights (535).
   With two nested loops it is 74 slots (88 with four directional targets) and runs 2,609 instructions for
   16 lights x 8 steps, 18,065 for 64 x 16, under the 65,535 run limit. Without the trace it also fits unrolled.

## Open issues

- **Inferred:** the host verdicts add the snippet to a host's slot count. The hosts' own temporaries were not
  measured; S3-02's offline run over every captured object shader has to check that host plus 16 stays within 32.
- **Open:** the shaders were validated by `fxc` only, not created on a Direct3D 9 device. `rep` with `texldl` is
  plain `ps_3_0`, but S3-02 and S2-02 should create one looped shader on the device and on the bridge once.
- **Open:** GPU time. Slots say what compiles, not what it costs: the wall-aware compose does 140 reads a texel and
  the looped gather 150-1100. Timing belongs to S2-02 and S3-02.
- The snippets' constants and atlas layout are placeholders. A third table texel for the cone and the per-lamp index
  texel of the looped form are assumptions S3-02 can change; the table is rebuilt by rerunning the tool.
