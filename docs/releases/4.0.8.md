# Apex Radiance 4.0.8

2026-11-19 · [v4.0.8](https://github.com/loinyx/Sims3-ApexRadiance/releases/tag/v4.0.8) · ApexRadianceSetup.exe, Apex-Radiance-4.0.8-Manual-install.zip

## Highlights

**No crash at start with Turbo Simulation Engine under the RTX Remix bridge.** With Turbo Simulation Engine installed,
the game could close while the first world loaded; it now starts as before. Nothing changes for players without Turbo
or without the bridge.

## Fixes

- **A crash at start with Turbo Simulation Engine under the RTX Remix bridge.** Since 3.2.2, Apex answers Turbo's second
  device request with the game's device (a second device stops the bridge's server). It handed out the first HAL device
  created, which can be a 0x0 probe device made before the game's own and released before Turbo asks: `AddRef` on the
  freed device closed the game (access violation in `Hooked_CreateDevice`, seen in a player's crash report). Turbo now
  gets the device Apex draws on, the one whose first `EndScene` started Apex's frame hooks
  ([RTX Remix bridge](../features/rtx-remix-bridge.md#compatibility-and-interactions)).

## Known limitations

- If Turbo asks for its device before the game's first frame, the request goes to the bridge as in 3.2.1.
