# Apex Radiance 2.12.0

2026-10-09 · [v2.12.0](https://github.com/loinyx/Sims3-ApexRadiance/releases/tag/v2.12.0) · ApexRadiance.asi

## Highlights

LUTs, presets and graphics improvements

## New features

- **3D CUBE LUTs:** load your own color looks alongside the existing PNG LUTs, then adjust their strength. LUTs have a dedicated area with a file selector, reset control and a shortcut to their folder.
- **A dedicated Presets page:** save your current settings, organize your presets and access the built-in Apex presets from the sidebar.
- **Easy preset sharing:** export and import TOML presets or ZIP packages. When a preset uses a LUT, Apex includes it automatically in the ZIP so everything travels in one file.
- **Restart Apex:** recreate the mod’s graphics resources from Settings → Compatibility without losing your settings or restarting the game.

## Changes

- Refined preset import and export dialogs, smaller buttons, consistent menus and better spacing and alignment.
- Clearer separation between your presets and the built-in Apex presets.
- More efficient lighting updates, file and object lookups, and internal resource handling.
- Updated documentation, in-game version notes and menu translations.

## Fixes

- Screen effects now preserve the game’s original transparency channel, avoiding unintended interference with brightness and colors.
- Improved graphics-state restoration, including clipping regions.
- Fixed a failure path that could leave Depth Blur inactive and retain a graphics resource.
- Improved handling of invalid settings, incomplete shader caches and shader replacements.
- Safer file exports and overwrite handling. Existing TOML presets remain supported.
- Developer settings in imported presets stay hidden and inactive in the public build.

## Upgrade notes

- Supports **3D CUBE** and supported **PNG LUTs**. One-dimensional CUBE files and combined shaper/3D files are not supported.
- Existing settings, presets and LUT folders remain compatible.
- Restart Apex refreshes graphics resources; it does not uninstall the mod or reset lighting hooks. Close the game before replacing or removing the ASI.

Close the game, then replace **ApexRadiance.asi** in **The Sims 3\Game\Bin\**. Your settings and saved presets are kept.
