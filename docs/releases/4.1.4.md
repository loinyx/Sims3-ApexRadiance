# Apex Radiance 4.1.4

Released 2026-11-26 · ApexLauncher.exe (also attached as ApexRadianceSetup.exe for older Setups' update), Apex-Radiance-4.1.4-Manual-install.zip

## Highlights

**Apex Launcher 2.3.3: update without playing, and the EA app version starts straight away.** Home has an update button
beside Play, Play on the EA app version of the game no longer goes through the Sims 3 launcher, and Play asks before it
fixes the game's files.

## Changes

- **Update button** ([home-and-play.md](../features/launcher/home-and-play.md)): while updates are ready, a square
  button beside Play (as *More options*) installs them in the install card and opens the done screen, without starting
  the game. A failed update says so in the update dialog, whose Back returns Home.
- **EA app version** ([home-and-play.md](../features/launcher/home-and-play.md)): Play asks the EA app to start the game
  through its `origin2://` link with the installer's content id and the Sims 3 launcher's `-editInGameMode:true0`, which
  starts `TS3.exe` at once without the launcher's window; a save's Play passes the save too. The launcher waits for the
  game off the window's thread.
- **Safe fixes** ([health.md](../features/launcher/health.md)): Play lists the fixable compatibility findings in *Fix the
  game's files first?* (*Fix and play*, *Play without fixing*, *Cancel*) instead of changing the files on its own. The
  *Apply safe fixes without asking* setting is off for everyone (a new key, `FixWithoutAsking`).
- **Home**: after the administrator window closes, the launcher opens on Home; the health crystal's light is much
  softer when Home has no picture.

## Fixes

- Shaders: in a narrow menu the look list took no width and showed only its arrow; it takes the row under its label
  again.

## Upgrade notes

The launcher updates itself; the mod is updated from the launcher's Components page or by the manual zip. Players who
want Play to keep fixing the game's files without asking turn *Apply safe fixes without asking* on again in Settings.
