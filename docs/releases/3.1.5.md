# Apex Radiance 3.1.5

2026-11-12 · [v3.1.5](https://github.com/loinyx/Sims3-ApexRadiance/releases/tag/v3.1.5) · ApexRadianceSetup.exe, Apex-Radiance-3.1.5-Manual-install.zip, ApexRadiance.asi, Apex-Radiance-RTX-Remix-bridge.zip

## Highlights

**Apex Radiance Setup fixes for the EA app.** Setup 1.1.1 installs Sims 3 Modernization on the EA app again and
recognises an EA app game moved to another folder. The mod itself is the same as 3.1.4.

## Changes

- **Downloads.** The manual install is one zip, `Apex-Radiance-3.1.5-Manual-install.zip` (`ApexRadiance.asi`,
  `ts3wrap.exe`, `How to install.txt`); `ApexRadiance.asi` and the RTX Remix bridge zip stay as files of their own for
  Setup, and `ts3wrap.exe` is no longer one. Setup 1.1.1 takes the ASI and `ts3wrap.exe` from the zip when they are not
  files of their own.
- **Settings > Credits** names Dalexlol's wrapper in sims3-modernization, which the restart host is adapted from.

## Fixes

- **Sims 3 Modernization on the EA app.** Its v0.2.11 has no EA app build, and Setup stopped every install with
  "asset not found". Setup now takes the newest of the last 10 releases that has the game's build (v0.2.10 for the EA
  app), with that release's `ts3fixes.package`, and offers no update to a release without it
  ([Apex Radiance Setup](../features/installer.md)).
- **A moved EA app game.** An EA app install moved out of the EA app's folder, with a `TS3W.exe` beside its `TS3.exe`,
  was taken for Steam, and its `bridge.conf` (`TS3.exe`) reported as wrong. The exe of a known game build now decides.

## Known limitations

- Setups of 3.1.3 and earlier do not update themselves: download this one once. Setup 1.1.0 (3.1.4) offers it on its
  start page.
