# Apex Radiance 2.4.0

Published 2026-10-01 · tag [`v2.4.0`](https://github.com/loinyx/Sims3-ApexRadiance/releases/tag/v2.4.0) · asset `ApexRadiance.asi`.

## Highlights

Smoother edges, texture sharpening and quicker street-lamp light.

## New features

- **Edges from depth:** SMAA and FXAA also find the edges of objects in the scene depth, so faint edges (walls against walls of the same color, night scenes) are smoothed too while textures stay sharp. On by default, in Display › Anti-aliasing.
- **Sharpen textures:** a new Anti-aliasing slider sharpens textures and leaves the smoothed edges alone. Off by default.
- **Temporal smoothing (SMAA, Experimental):** while the camera moves, each frame is blended with the last one, so thin lines, fences and far edges shimmer much less. With the camera still the picture is plain SMAA. Off by default.
- **Faster memory handling (Experimental):** the game's memory manager waits a few microseconds before sleeping, and big blocks are handed back to Windows in the background. Off until you turn it on in Performance.

## Changes

- **Faster cache compression:** the caches' checksums are computed faster too, with the same result.

## Fixes

- **Night Lights:** a lot whose lamps all switch together (a town square at night) now lights the ground within seconds, lamps switched on and off a few times are no longer ignored afterwards, and a lamp change waits at most 2 seconds for the camera to stop.

## Upgrade notes

Close the game, then replace `ApexRadiance.asi` in `The Sims 3\Game\Bin\`. Your settings are kept.
