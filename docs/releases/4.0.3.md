# Apex Radiance 4.0.3

2026-11-17 · [v4.0.3](https://github.com/loinyx/Sims3-ApexRadiance/releases/tag/v4.0.3) · ApexRadianceSetup.exe, Apex-Radiance-4.0.3-Manual-install.zip

## Highlights

**One-click frame generation in Setup.** Apex Radiance Setup 1.2.6 turns on NVIDIA Smooth Motion (GeForce RTX 40 and
50 series) or AMD Fluid Motion Frames (cards whose driver supports it). It also sets Apex's frame limit, with 60 to
90 fps suggested, and fails more clearly on players' PCs.

## Changes

- **NVIDIA Smooth Motion switch.**
  - **How it is set:** Setup edits the driver profile that holds `NvRemixBridge.exe`, NVIDIA's own "NvRemixBridge"
    profile, the way NVIDIA Profile Inspector does: through the same interface IDs, falling back to the public ones.
    It sets "Smooth Motion - Enable" to on and "Enabled APIs" to DX12, DX11 and Vulkan.
  - **Turning it off:** puts both settings back to NVIDIA's defaults, and only when Setup turned them on.
  - **What it needs:** a GeForce RTX 40 or 50 series card (laptop GPUs included), driver 571.86 or newer, and the RTX
    Remix bridge.
  - **Checked in game:** the NVIDIA app lists the bridge as not compatible, but the forced setting works: the
    maintainer saw it on an RTX 40-series card ([Apex Radiance Setup](../features/installer.md)).
- **AMD Fluid Motion Frames switch.** Set through AMD's ADLX, shown only where the driver says it is supported. AFMF is
  one setting for the whole card, so the row says it applies to every game. Setup records that it turned AFMF on, and
  only then turns it off again.
- **One frame generation row.** Only the row that applies to the PC is shown, and its icon changes to a film frame.
- **Apex frame limit in Setup.** A picker below frame generation, with a gauge icon. It names the feature shown above it
  and shows what the player gets, for example "60 fps → about 120 fps on screen".
  - Choices: off, 30, 60, 75, 90, 120, 144, 165, 240 or a custom value; 60, 75 and 90 are marked as recommended.
  - Turning frame generation on sets 60 only when there is no limit; a limit the player chose stays.
- **Changes wait for Apply.** The frame generation switches and the frame limit apply only when the player clicks
  Apply. Each change gets its own task row and restore point. After writing to the driver, Setup reads the setting back
  and says plainly when it did not take, with a link to the manual steps.
- **Maintenance.** Removing the RTX Remix bridge or Apex Radiance, switching away from the bridge, or uninstalling
  everything turns frame generation off, after the files are removed. A driver error never fails the removal.
- **Reliability on players' PCs.**
  - **Log:** a log in the player's own `%LOCALAPPDATA%\Apex Radiance Setup\`. Error notices get Copy details and Open
    log folder.
  - **Checks before downloading anything:**
    - the game, its launcher, the restart host and the bridge's server are closed;
    - `Game\Bin` and Documents are writable;
    - there is enough free space;
    - a foreign `d3d9.dll` (ReShade, GShade) or a second ASI loader is named before it is set aside.
  - **A failed install is undone automatically**, and keeping what was installed is a choice.
  - **File writes:** read-only files no longer block installs or removals. Copies and deletes retry when another
    program briefly holds a file. A damaged `setup.json` is rebuilt from the backup folder.
  - **Downloads:** GitHub downloads retry. GitHub's rate limit, a dropped connection, a damaged download and an
    antivirus removing a file each get their own message.
  - **Setup updates:** a Setup update starts the new Setup before closing the old one, and puts the old one back if
    the new one cannot start.
  - **ASI loader:** still the latest Ultimate ASI Loader release, now found by its 32-bit zip's name pattern.
- **Sims 3 Modernization first** among the optional mods, and **a cleaner game list**: the chosen game shows by its
  card's accent outline.
- **Smooth Motion in the README.** The README explains how to turn Smooth Motion on by hand with NVIDIA Profile
  Inspector, for players who don't use Setup.

## Fixes

- **The menu's font on Linux.** Under Wine and Proton, where Segoe UI is missing, the menu uses the system's Noto Sans,
  DejaVu Sans or Liberation Sans (through `Z:`), else the Tahoma or Arial Wine ships, instead of ImGui's blurry pixel
  font. Untested on a Linux machine; the log names the font it took.
- **Setup notices** line up: their buttons start at the title's left edge.

## Known limitations

- **AMD Fluid Motion Frames:** the write is unverified on a real card, untested on an RX 6000-series or newer card, and
  untested under the RTX Remix bridge.
- **NVIDIA Smooth Motion:** the driver write was checked on one PC (RTX 4070 Ti SUPER, driver 621.24): a read-back after
  it shows the setting stored in NVIDIA's "NvRemixBridge" profile. Other drivers and cards are covered by tests only.
- **EA app 1.69:** the handling is covered by tests on a fake game, not on a real EA app install.
- **Ultimate ASI Loader 10:** it can show a "Select Override (Update) Folder" dialog at start. One EA app player saw a
  window like it, and what triggers it is unverified.
- **Proxy:** when Setup is elevated as a different administrator, it uses that account's proxy settings.
- **UI checks:** an automated UI run exercised every control in a dry run. Three notices it cannot reach in a dry run
  (rate limit, antivirus, update offer) were not checked by eye.

## Upgrade notes

Setup 1.2.6 offers itself to players with an older Setup. No settings change in the mod.
