# Apex Radiance 2.11.1

2026-10-08 · [v2.11.1](https://github.com/loinyx/Sims3-ApexRadiance/releases/tag/v2.11.1) · ApexRadiance.asi

## Changes

- **Ambient Occlusion:** removed Temporal smoothing, Thin object detail and its Object thickness control. Their shaders and temporal history textures are removed too.
- **AO remains available:** the main effect, five quality levels, map-view shading and separate Sim/hair controls remain.
- **Existing settings:** old keys for the removed options are ignored. Other adjustments are kept.
- **In-game notes:** updated What's new and its translations.

## Known limitations

- Removing temporal blending or thin-object detail changes the AO result when those options were previously enabled. This release does not claim identical shading to those removed modes.
- Gameplay and cross-backend visual verification of this release remain pending.

## Upgrade notes

Close the game, then replace ApexRadiance.asi in The Sims 3\Game\Bin\. Your other settings are kept.
