# Apex Radiance 3.1.4

2026-11-12 · [v3.1.4](https://github.com/loinyx/Sims3-ApexRadiance/releases/tag/v3.1.4) · ApexRadiance.asi, ApexRadianceSetup.exe, ts3wrap.exe

## Highlights

**Apex Radiance Setup keeps itself up to date.** Setup now shows on its start page when a newer Setup is out, and
updates itself with one click. The mod itself is the same as 3.1.3.

## Changes

- **Setup's own update.** Setup 1.1.0 compares itself with the `ApexRadianceSetup.exe` of the latest release: a newer
  one is downloaded, checked against GitHub's SHA-256 digest and its product name and version, and offered on the
  welcome page (*A new Setup is available*, *Update Setup*); Setup then restarts as the new version
  ([Apex Radiance Setup](../features/installer.md)).

## Known limitations

- Setups of 3.1.3 and earlier do not look for a newer Setup: download this one once from the release page.
