# Apex Radiance 3.2.1

2026-11-13 · [v3.2.1](https://github.com/loinyx/Sims3-ApexRadiance/releases/tag/v3.2.1) · ApexRadianceSetup.exe, Apex-Radiance-3.2.1-Manual-install.zip

## Highlights

**Apex Radiance Setup checks the graphics driver before installing DXVK.** Setup 1.1.3 offers DXVK and the RTX Remix
bridge only when the graphics card and its driver have what DXVK needs, and asks for a driver update when the driver is
too old. The mod itself is the same as 3.2.0 for players.

## Changes

- **Developer mode files.** The per-session files of developer mode (`MemoryAnalysis`, `GameplayMemory`, `GameCategories`,
  `AddressOwners`, `LotLoadAnalysis`, `RoomLampProbe`, and the `calib_*.bmp` map comparisons) go to `Diagnostics\` in the
  Apex Radiance folder, and only the newest 10 of each kind stay; copies left at the root by older builds move there
  ([interface](../ui.md#generated-folders)). With developer mode off, nothing changes.

- **MonoPatcher** is no longer offered by Setup: no mod Setup installs needs it, and it crashed the game's launcher on a
  player's PC. Where it is installed, Setup still shows it, so it can be kept or removed
  ([Apex Radiance Setup](../features/installer.md)).

## Fixes

- **A game that closed at start after Setup installed DXVK.** DXVK 3.1.1 needs Vulkan 1.3 and six device extensions;
  Setup checked only the Vulkan version, and only for the RTX Remix bridge. An Intel Iris Xe on driver 101.4502 (Vulkan
  1.3, no `VK_KHR_load_store_op_none`, which Iris Xe drivers have from 101.6556) got DXVK, which found no adapter. Setup
  now asks the driver for those extensions: a card without Vulkan 1.3 gets the game's own Direct3D 9, an old driver gets a
  request to update it, and an installed DXVK or bridge that cannot start shows an error with the vendor's driver page
  ([Apex Radiance Setup](../features/installer.md)).

## Known limitations

- The new Setup messages were checked offline and on a card with every extension; they have not been seen on a PC with
  an old driver.
- Setups before 1.1.3 still offer DXVK on such drivers: Setup 1.1.0 and later offer this one on their start page.
