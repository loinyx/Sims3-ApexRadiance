# Apex Radiance 2.14.0

2026-10-19 · [v2.14.0](https://github.com/loinyx/Sims3-ApexRadiance/releases/tag/v2.14.0) · ApexRadiance.asi

## Highlights

Hotfix for save preparation, bounded memory reuse and lamp blocking.

## Changes

- **Room to save:** releases idle buffers earlier during saving. Completed compression storage and deferred frees are
  released while pending compression writes remain protected. Early native dispatch preparation requires the verified
  Steam executable; other builds keep the existing world-save preparation.
- **Screen effects:** avoid unused image copies and repeated timing work. The fallback scene copy is created on
  demand; public effect timing queries are sampled rather than issued every frame. Effect quality is unchanged.
- **Object and compression caches:** reduce repeated work with bounded memory. Repeated texture strips reuse identical
  encoded bytes, ordered CAS lists skip sorting, and object/type lookups keep validated cached results. Idle compression
  storage is retired and active output copies have a shared budget.

## Fixes

- **Night Lights:** improves lamp blocking near stairs and closed floors. Opaque collected triangles retain real gaps;
  higher-coverage surfaces can replace narrow details when collection fills. Wall support rows cannot borrow lamp light
  through a closed floor, and imported directional light uses the receiving room's normalization.
- **Object lookup cache:** expired local entries can obtain the refreshed shared entry instead of repeating native
  searches indefinitely.

## Known limitations

- Error 12 is not eliminated. The game remains constrained by its 32-bit address space, and save memory endpoints do
  not measure the peak. Native cache accounting is distinct from RAM returned to Windows.
- Mesh collection is bounded and requires compatible opaque geometry to be drawn first. Complete stair coverage,
  coloured wall leakage and arch continuity remain unverified in the final release build.
- No substantial FPS or RAM reduction is established by the offline checks. Earlier gameplay feedback reports a small
  improvement; the standard release build requires its own in-game validation.
- Early save dispatch and partial native cache control are validated only for Steam 1.67. Other supported builds keep
  signature-resolved existing paths; this does not establish identical internal layouts across versions.
