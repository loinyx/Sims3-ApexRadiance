# Apex Radiance 4.1.5

Released 2026-11-26 · ApexLauncher.exe (also attached as ApexRadianceSetup.exe for older Setups' update), Apex-Radiance-4.1.5-Manual-install.zip

## Highlights

**Apex Launcher 2.3.4: the note that the game closed on its own can be closed.** Home's warning after a game that
ended badly now has a close button, and a session no longer takes a game started by Apex Radiance's test runner for
the player's.

## Changes

- **Home** ([home-and-play.md](../features/launcher/home-and-play.md)): *The game closed on its own* and *Ran out of
  memory* have a close button; closing one hides that session's note for good (`SessionDismissed` in `settings.json`).
- **Session** ([home-and-play.md](../features/launcher/home-and-play.md)): when the game closes, the session no longer
  follows a game started by the test runner (`-ApexTestAgent` in its command line) as a restart; its minutes and crash
  files no longer showed as the player's game closing on its own.

## Upgrade notes

The launcher updates itself; the mod is updated from the launcher's Components page or by the manual zip. The mod
itself changes only its version and What's new.
