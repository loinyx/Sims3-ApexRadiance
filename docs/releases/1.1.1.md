# Apex Radiance 1.1.1

Published 2026-09-28 · tag [`v1.1.1`](https://github.com/loinyx/Sims3-ApexRadiance/releases/tag/v1.1.1) · asset `ApexRadiance.asi`.

## Highlights

Night Lights: faster, cleaner, seamless.

## Changes

- **One rebuild when a save loads**, once the world is actually running (no more extra rebuilds during the loading screen).
- **Smoothing on the GPU:** the soft ground light is now computed on the graphics card in the same frame the game updates it.
- Menu options such as "Lot lamps light the street" apply instantly.

## Fixes

- **Lights show up right away:** after loading a save, moving the camera or placing and editing lamps in Build mode, the lamp light appears correct almost immediately instead of showing an old result first and fixing itself seconds later. New or deleted lamps now update in about a second.
- **No more hard light line at lot edges:** a lamp post standing next to a lot border no longer makes the lot's grass much brighter than the ground right outside. The lot ground now blends into the surrounding terrain light over the last few metres.

## Known limitations

The lighting features still require The Sims 3 Steam 1.67.2. Support for the EA App version (1.69) is being worked on.

## Upgrade notes

Close the game, then replace `ApexRadiance.asi` in `The Sims 3\Game\Bin\`. Your settings are kept.
