# Apex Radiance 4.0.9

2026-11-19 · [v4.0.9](https://github.com/loinyx/Sims3-ApexRadiance/releases/tag/v4.0.9) · ApexRadianceSetup.exe, Apex-Radiance-4.0.9-Manual-install.zip

## Highlights

**Screenshots and videos with a 10-bit screen.** When another mod sets the game's screen to 10 bits (a separate banding
mod does), screenshots saved nothing and videos refused to start; both now work.

## Fixes

- **No screenshots or videos with a 10-bit screen.** Both read the picture as 8-bit `X8R8G8B8` and refused any other
  back-buffer format: the log said `Video not started: the screen format 35 cannot be recorded` (35 is `A2R10G10B10`)
  and `No screenshot: the screen format could not be read`. A player's `BandingFix.asi` set that format. The back buffer
  is now copied into an 8-bit target by `StretchRect` on the GPU, which converts it; video tries one copy at start and
  still refuses a format the GPU cannot convert ([Screenshots and video](../features/screenshots-and-video.md)).

## Known limitations

- Checked offline on native Direct3D 9 (`tools/capture_format_check`); not yet run in game with a 10-bit screen.
