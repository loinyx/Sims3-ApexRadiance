# Apex Radiance 4.1.7

Released 2026-11-26 · ApexLauncher.exe (also attached as ApexRadianceSetup.exe for older Setups' update), Apex-Radiance-4.1.7-Manual-install.zip

## Highlights

**Apex Launcher 2.3.6: its own update sits with the others.** A newer launcher no longer opens a window of its own: it
is one more line on Home's update button beside Play.

## Changes

- **Self-update** ([self-update.md](../features/launcher/self-update.md)): once a newer launcher is downloaded and
  checked, Home's update button counts and lists it (*Apex Launcher X*); the button installs it last, after the other
  updates, since it restarts the launcher. The *Apex Launcher X is ready* dialog is gone.

## Upgrade notes

The launcher updates itself; the mod changes only its version and What's new.
