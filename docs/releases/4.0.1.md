# Apex Radiance 4.0.1

2026-11-15 · [v4.0.1](https://github.com/loinyx/Sims3-ApexRadiance/releases/tag/v4.0.1) · ApexRadianceSetup.exe, Apex-Radiance-4.0.1-Manual-install.zip

## Highlights

**The RTX Remix bridge is now the recommended renderer.** Apex Radiance Setup 1.1.7 picks the RTX Remix bridge on a
first install, with DXVK when the graphics card cannot run the bridge.

## Changes

- **Apex Radiance Setup 1.1.7 installs the RTX Remix bridge by default.** On a first install the bridge is the selected
  renderer; when the graphics driver cannot run it, DXVK is selected instead. An existing install keeps the renderer it
  has ([Apex Radiance Setup](../features/installer.md)).
- **The bridge is recommended everywhere.** Setup's compatibility check and the in-game Recommended card recommend the
  RTX Remix bridge, with DXVK as the fallback.
