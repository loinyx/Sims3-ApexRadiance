# Apex Radiance 3.2.2

2026-11-13 · [v3.2.2](https://github.com/loinyx/Sims3-ApexRadiance/releases/tag/v3.2.2) · ApexRadianceSetup.exe, Apex-Radiance-3.2.2-Manual-install.zip

## Highlights

**The RTX Remix bridge works with Turbo Simulation Engine.** With Turbo Simulation Engine installed, the game froze at
start under the bridge; it now starts and plays normally. Nothing changes for players without Turbo or without the
bridge.

## Fixes

- **A freeze at start with Turbo Simulation Engine under the RTX Remix bridge.** `Turbo.asi` creates a second Direct3D 9
  device after the game's (a 0x0 back buffer on its own hidden window) to read the device functions for its menu. The
  bridge serves one device: at the second, its server stopped answering and the game waited forever at its next Present.
  With `Turbo.asi` loaded and the bridge running, Apex answers that request with the game's device and one more
  reference, which Turbo's release gives back. Measured with the in-game runner on a town save: with 3.2.1 the game hung
  at start with Turbo; with the fix, Turbo alone and Turbo with Sims3SettingsSetter ran the whole route
  ([RTX Remix bridge](../features/rtx-remix-bridge.md#compatibility-and-interactions)).

## Known limitations

- Checked under the RTX Remix bridge only; Turbo with DXVK in the game or the game's own Direct3D 9 was not run (it is
  left as before).
- Turbo's menu (F7) was not opened in these runs. Its key also fires on Apex's Ctrl+Shift+F7.
