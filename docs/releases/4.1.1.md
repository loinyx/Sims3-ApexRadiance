# Apex Radiance 4.1.1

2026-11-25 · ApexLauncher.exe (also attached as ApexRadianceSetup.exe for older Setups' update), Apex-Radiance-4.1.1-Manual-install.zip

## Highlights

**Apex Launcher 2.3.** A Game settings page, adding mods, Sims, lots, worlds and archives, mod profiles, merges that are
edited in one go and keep the window responsive with thousands of mods, and a Saves page with backups, automatic ones
too, that cleans a save with Undo.

**Deleting lamps in Buy mode.** Two causes of faults and crashes after lamps are deleted are fixed, contributed by
@rodneypantonial.

## Changes

- **Game settings** ([Apex Launcher](../features/installer.md#the-launcher-200)): shadow and Sim texture size, bloom,
  reads in flight, the walking values and the game's own options, also as a step of a first install. Only a changed value
  is written, each file is copied first, and *Restore my files* puts them back. A graphics card the game does not know
  can be added to its list.
- **Home:** the main button opens the game's main menu; the newest saves stand in one row, each with its own Play
  button.
- **Mods:** sortable columns, filters and a select-all box; details with content, conflicts, replaced items and notes; a
  bar of actions for a selection; profiles; a page address per mod; *Open in s3pe*; *Find custom content*; caches
  cleared by group.
- **Adding files:** packages, Sims, lots, households, worlds, archives and folders, each to its own place, compared with
  what is installed. A package that looks damaged can be added by ticking it.
- **Merges:** mods that change the same game data stay out until the player decides and orders them; a merge is changed,
  updated and split in one go, with every step undone when it fails or the launcher ends midway; originals are kept in
  `Merged (Apex Launcher)` next to Mods. A merge reads each source once and its result once.
- **Conflicts and Health:** one page per check; every notice can be ignored; tuning, texts, settings files and window
  layouts are compared by what the game reads, so copies that mean the same are no conflict.
- **Saves:** each save with its backups and what can be cleaned, to the byte; rename, duplicate and delete; lost saves and
  saves kept out of the game in the same list.
- **Backups of saves:** made when asked or, when chosen, as the game closes, before Play or once a day, with a
  number to keep, a space limit and a folder to choose; restored over the save or opened as another one, with the missing
  mods told; named, pinned, checked, exported and imported.
- **Look:** a design system for the launcher ([launcher-design.md](../launcher-design.md)): neutral dark and light surfaces,
  eleven colour themes and one that follows Windows, one family of icons, the same distances and rows on every screen. The
  install, Saves and Mods are drawn anew, and every dialog, menu, message and field has one shape.
- **Texts:** rewritten with one word for each thing, and translated into the launcher's 21 languages with the texts of 4.1.0.
- **Installing the launcher:** one screen with the folder to install to, the desktop shortcut and Start with Windows;
  an installed launcher moves to another folder in Settings, and uninstalling from a chosen folder takes only its own files.
- **MonoPatcher** can be installed from Components and the first install again, off until it is turned on.
- **Documents folder:** the mod and the launcher use the folder of the game's own language, as `TS3W.exe` does
  ([architecture.md](../architecture.md)). Apex's settings left in the folder of Windows' language move along.

## Fixes

- **Night Lighting:** the directional map step leaves out a lamp that was destroyed while the lamp snapshot still holds
  it (`BasisStep`, `BasisPartNow`; [gpu-room-lamps.md](../features/night-lighting/gpu-room-lamps.md)), and the terrain
  stamps leave out a lamp the game has freed (`StampOf`;
  [terrain-relight.md](../features/night-lighting/terrain-relight.md)). Contributed by @rodneypantonial.
- A save opened from the launcher or the restart host keeps its name in the game: Save As shows, and the first Save no
  longer asks for a name ([save-name-fix.md](../features/save-name-fix.md)).
- Health names a mod for a script error only when the mod threw it or made the call that failed.
- A mod folder whose antivirus file blocks its removal no longer stops a merge, an undone install or an uninstall.
- A package index whose sizes lack the top bit is read whole.
- Changing between light and dark no longer closes the launcher after a few changes.
- The update offer of the launcher no longer closes a dialog that is open, such as an uninstall started from Installed apps.

## Known limitations

- Not verified in game: a save restored from a backup, a cleaned save, a package merged by 2.3, the Game settings values, and which of two lighting
  mods on `LightingCommon` wins by name order.
- The deleted lamp fixes were tested by their author with the RTX Remix bridge on Steam 1.67; not run with DXVK, the
  Windows renderer or the EA app edition.
- The new texts outside Portuguese were not read by native speakers.

## Upgrade notes

- The launcher updates itself from 2.0.30 to 2.3.0.
- Merges kept inside `Mods\Merged (Apex Launcher)` move next to Mods.
- No setting of Apex Radiance moves, except to the Documents folder of the game's language when it differs.
