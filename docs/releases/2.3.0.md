# Apex Radiance 2.3.0

Published 2026-09-30 · tag [`v2.3.0`](https://github.com/loinyx/Sims3-ApexRadiance/releases/tag/v2.3.0) · asset `ApexRadiance.asi`.

## Highlights

Light between floors fixed, 3x faster cache compression, faster Sim building.

## New features

- **Faster Sim building (new, Experimental, off by default):** when the game builds a Sim (Create a Sim, outfit changes) it sorts the triangles of hair and see-through clothing with a very slow test. Apex does the same sort many times faster, with exactly the same result. Turn it on in System > Performance.

## Changes

- **Faster cache compression (Experimental):** big Sim caches are now split over several processor cores and never compressed twice, with the same game format. The ~300 ms freezes when the game stores Sims dropped to ~100 ms in testing.

## Fixes

- **Light between floors:** double-height rooms and open floors now let lamps light the floor above (and below) as soon as the lot loads. Before, the game sometimes kept the upper walls dark until you left and entered the lot again.

## Upgrade notes

Close the game, then replace `ApexRadiance.asi` in `The Sims 3\Game\Bin\`. Your settings are kept.
