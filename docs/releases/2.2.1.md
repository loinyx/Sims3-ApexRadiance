# Apex Radiance 2.2.1

Published 2026-09-30 · tag [`v2.2.1`](https://github.com/loinyx/Sims3-ApexRadiance/releases/tag/v2.2.1) · asset `ApexRadiance.asi`.

## Highlights

Banding Fix is now Experimental, with a 0-100% Strength and an optional Moving grain.

## New features

- **Moving grain (new, off by default):** the grain changes every frame, so at high frame rates it becomes invisible and gradients look even smoother; at low frame rates it can look like a faint shimmer.

## Changes

- **Banding Fix (Experimental):** it stays on by default, now labeled Experimental while more players try it. If anything looks wrong, turn it off in Color › Banding.
- **Strength from 0 to 100%:** 100% is the full grain that hides the color steps and stays the default; lower it for a finer grain, 0% turns the grain off. A higher value you set before is brought down to 100%.

## Fixes

- **Ambient Occlusion grain fix:** Ambient Occlusion added the same grain a second time on top of the picture, which made it look slightly speckled, even with the Banding Fix off. Its grain now follows the Banding Fix and only goes where the shade darkens the picture.

## Upgrade notes

**Ambient Occlusion settings reset once** to the defaults after this update.

Close the game, then replace `ApexRadiance.asi` in `The Sims 3\Game\Bin\`. Your settings are kept.
