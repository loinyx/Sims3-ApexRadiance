# Apex Radiance 2.5.6

Published 2026-10-03 · tag [`v2.5.6`](https://github.com/loinyx/Sims3-ApexRadiance/releases/tag/v2.5.6) · asset `ApexRadiance.asi`.

## Highlights

Responsive World Lights and Rendering Optimizations.

## New features

- **Sidewalks:** Added support for the alpha-blended sidewalk shader variant that packs opacity and terrain UVs together.
- **Optimize rendering:** Enabled by default for new or missing settings. Reuses prepared lamp constants and chunk traversal indexes, combines adjacent shader-constant reads, and avoids repeated metadata queries for known terrain textures. Existing explicit off settings are preserved. Resolution, filters, light counts and lighting-update budgets are unchanged. Overall FPS gains have not been measured.

## Changes

- **Developer profiler:** Optional per-hook timing now separates state callbacks by method. Disable detailed timing for performance comparisons.

## Fixes

- **World street lamps:** Fixed colour-change tracking for street lamps outside lots. Observed edits now reconcile terrain lightmaps and request a coalesced refresh of native object-light rigs.
- **Ground lighting:** Completed local terrain updates notify the smoothing cache when the game finishes through its alternate LOD path.

## Known limitations

The world-lamp colour response was confirmed in a player test. Offline policy and constant-read checks passed, and the Release x86 binary compiled successfully. Broader gameplay coverage and paired performance measurements remain pending.

## Upgrade notes

Close the game and launcher, back up the previous ASI, then replace `ApexRadiance.asi` in `The Sims 3\Game\Bin\`. Keep only one Apex Radiance ASI in that folder. Existing settings are retained.
