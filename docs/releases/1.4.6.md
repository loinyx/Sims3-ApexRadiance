# Apex Radiance 1.4.6

Published 2026-09-29 · tag [`v1.4.6`](https://github.com/loinyx/Sims3-ApexRadiance/releases/tag/v1.4.6) · asset `ApexRadiance.asi`.

## Highlights

Color fix.

## Changes

- **When the game draws its picture in a way Apex can't split** (usually when the game's own Edge Smoothing is on), Color now still applies to the whole picture instead of doing nothing, and the Color card tells you that the game's menus get tinted too.
- The log now records screen resets, to help with future reports.

## Fixes

- **Color works again when it's already on as the game starts.** If you quit the game with Color on, on the next start its sliders could change nothing: the game resets its screen while loading, and Color kept looking at the loading screen's picture. It now follows the reset. (Turning Color off and on again was the workaround.) Thanks Elix for pinning it down!
- The same reset is now also followed by Edge Smoothing and Depth Blur.

## Upgrade notes

Close the game, then replace `ApexRadiance.asi` in `The Sims 3\Game\Bin\`. Your settings are kept.
