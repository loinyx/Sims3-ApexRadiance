# Apex Radiance 2.15.0

Pending · [v2.15.0](https://github.com/loinyx/Sims3-ApexRadiance/releases/tag/v2.15.0) · ApexRadiance.asi

## Highlights

Faster indoor light on lot entry and floor changes, furniture and floors that change together and share their room's
colour, less memory in long sessions, and the first support for the Steam Deck and Linux.

## New features

- **Steam Deck and Linux:** Apex Radiance recognises Proton, the Steam Deck and DXVK, shows them in Settings >
  Compatibility, carries its own shaders already compiled (the game under Proton no longer needs a compiler for them),
  and suggests the Performance preset on the Deck without touching the lighting. See
  [steam-deck.md](../features/steam-deck.md).

## Changes

- **Indoor lights sooner:** entering a lot opens the same settle window as a load; lamps the game switches on other lots
  no longer go before the played lot's rooms; room 0 of other stories comes after the camera's story; the window recheck
  no longer solves window rooms again when no window changed; with every floor detailed, the camera's story is solved
  first, then the stories below it, then those above; a lamp edit no longer makes every story's room 0 solve in full
  again.
- **Furniture with its floor:** an edit's furniture waits for its room's new light from the edit's start, vertex-lit parts
  included, so objects and floors change together.
- **Furniture color:** in a lit room the furniture's fill light takes the hue of the room's ambient, as the walls do.
- **Memory:** data kept only for lots that left is given back.
- **Ambient Occlusion and Depth Blur** name the reason when the shared depth is not ready.
- **Menu:** descriptions brought in line with what each option does today (lamp brightness on objects and trees,
  memory options, Water Reflections needing Depth Blur or Ambient Occlusion, Edge Smoothing methods, presets).
- **Light capture** takes one capture; the automatic re-captures after a floor change are gone.
- **Presets:** the Performance part now sets all fifteen Performance switches and the lamp lighting mode (the mode was
  saved with the Night Lights part). The built-in Default preset is now called Balanced: it is a balance of looks and
  speed, not the code defaults.
- **Overview > All effects** keeps Room to save on when it turns everything off, so the save guard is not lost.
- **Borrowed light:** rooms lit through an arch and rooms lit through a floor opening follow one adaptation rule, capped
  at x1.4 (it was up to x2 for floor openings), and a room is never shown darker than an empty room.

## Fixes

- **Lamp light from another floor** no longer passes through the walls of the story below an opening (a lamp over an
  atrium lit a room behind two walls downstairs).
- **Arches and doors** keep letting light through after Night Lights is switched off and on.
- **Depth Blur's Distance** no longer shows as changed at its default.
- **Rooms that take almost no light** are no longer brought up x2 by the partial eye adaptation.

## Known limitations

- None of this is confirmed on the Steam Deck yet.
- Large lamp edits on big houses still take several seconds: most of the time is the game's own room solve at the top
  quality on every story.
