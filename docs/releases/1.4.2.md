# Apex Radiance 1.4.2

Published 2026-09-29 · tag [`v1.4.2`](https://github.com/loinyx/Sims3-ApexRadiance/releases/tag/v1.4.2) · asset `ApexRadiance.asi`.

## Highlights

Spread new objects over frames is back (experimental).

## New features

- **Spread new objects over frames (off by default, System > Performance):** while the camera moves, new objects join the scene over a few frames instead of all at once, for fewer hitches when a lot streams in. When the camera stops, everything comes in as usual.

## Changes

- It is now guarded: when the game deletes an object, adds it to a scene again or tears a scene down, Apex Radiance takes that object out of its waiting list first, so a held object can never be used after the game let it go.
- It is also part of the **Performance** part of profiles.

## Known limitations

Like every performance option it carries the **Experimental** label: if anything looks wrong, turn it off. If the game crashes, please attach `ApexRadiance_Crash.txt` from `Documents\Electronic Arts\The Sims 3\Apex Radiance\`.

## Upgrade notes

Close the game, then replace `ApexRadiance.asi` in `The Sims 3\Game\Bin\`. Your settings are kept.
