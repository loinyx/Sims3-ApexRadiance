# Apex Radiance 2.17.2

[v2.17.2](https://github.com/loinyx/Sims3-ApexRadiance/releases/tag/v2.17.2) · ApexRadiance.asi

## Highlights

Apex now recognises Sims 3 Modernization and Sims 3 Performance Patch. When both are installed and Short Wait Spin or
Thread Stack Diet is on in Sims 3 Performance Patch, a combination that can freeze Sims and the camera for minutes, Apex
asks once whether to turn the two options off and can do it for you.

## New features

- **Other performance mods in Settings > Compatibility:** rows for Sims 3 Modernization and Sims 3 Performance Patch,
  each shown only when loaded. With both loaded and `ShortWaitSpin` or `ThreadStackDiet` set to 1 in `[Patches]` of
  `Sims3Performance.ini`, the Sims 3 Performance Patch row says *Settings to change*, and the RECOMMENDED group (also on
  the Overview card) explains why and offers **Turn off** and **Open Sims3Performance.ini**. Sims 3 Modernization's
  author recommends both options off.
- **One-time question:** after the Room to save question, a card with the menu closed asks *Turn off Short Wait Spin?*
  (**Not now** / **Turn off**); either answer is remembered in `[ui] s3pp_spin_asked`.
- **Turn off** copies the file to `Sims3Performance.ini.apex-backup`, then writes 0 in those two values only; every
  other line stays as it was. The file is never changed without that click.

## Changes

- The Room to save question and the new question share one card layout; the Room to save card looks and behaves as
  before.

## Known limitations

- The change takes effect at the next game start, since Sims 3 Performance Patch reads its file only then; the row and
  the item say so after the click.
- Checked in game with Sims 3 Modernization 0.36.37 and Sims 3 Performance Patch 1.0.0-beta2 (detection, both answers'
  file change and backup, the question shown once). The freeze itself was confirmed with both options on and gone with
  both off on one save; Thread Stack Diet is turned off on its author's recommendation, not on a separate measurement.
- The mods are recognised by their file names (`ts3native.asi`, `Sims3Performance.asi`); a renamed file is not seen.

## Upgrade notes

None for players without these mods. A new `[ui] s3pp_spin_asked` key is written once the question is answered; Reset
all settings keeps it.
