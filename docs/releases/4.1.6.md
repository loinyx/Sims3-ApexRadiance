# Apex Radiance 4.1.6

Released 2026-11-26 · ApexLauncher.exe (also attached as ApexRadianceSetup.exe for older Setups' update), Apex-Radiance-4.1.6-Manual-install.zip

## Highlights

**Saves opened on the EA app version run normally.** Apex Launcher 2.3.5 and Apex Radiance 4.1.6 fix a save opened
from Apex Launcher on the EA app version starting paused, with time that could not be started.

## Fixes

- EA app version ([home-and-play.md](../features/launcher/home-and-play.md)): the Sims 3 launcher's
  `-editInGameMode:true`, which Apex Launcher uses to skip that launcher's window, also reached the game, which loaded
  the save in its edit mode with time stopped (any value starting with `t` or `1` turns it on). Apex Launcher now adds
  `-apexDirect`, and Apex Radiance renames `editInGameMode` in the game's command line before the game reads it. The
  direct start is used only with Apex Radiance 4.1.6 or later installed; with an older one Play opens the Sims 3
  launcher as before.

## Upgrade notes

Update both: Apex Launcher updates itself, and Play installs Apex Radiance 4.1.6 first when updates install on Play.
