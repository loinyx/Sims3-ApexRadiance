# Apex Radiance 4.0.10

2026-11-19 · [v4.0.10](https://github.com/loinyx/Sims3-ApexRadiance/releases/tag/v4.0.10) · ApexRadianceSetup.exe, Apex-Radiance-4.0.10-Manual-install.zip

## Highlights

**System > Display opens with every mod.** When another mod made a graphics device of its own after the game's,
opening the Display page could crash the game; it now opens as usual.

## Fixes

- **Crash opening System > Display.** Apex's `CreateDevice` hook handed every hardware device to Display, so a device
  another mod made after the game's (a player's log: 120x61, after the first Present, Turbo.asi loaded) replaced the
  game's `IDirect3D9` and window there. That device was released with its `IDirect3D9`, and listing the resolutions
  called it: the crash report showed `Screen::RenderUI` calling through a freed object. Display now follows the game's
  device only ([Display](../features/display.md)).

## Known limitations

- Traced from a player's crash report and log; not yet run in game with that mod set.
