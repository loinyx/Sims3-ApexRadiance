# Apex Radiance 4.0.14

2026-11-23 · [v4.0.14](https://github.com/loinyx/Sims3-ApexRadiance/releases/tag/v4.0.14) · ApexRadianceSetup.exe, Apex-Radiance-4.0.14-Manual-install.zip

## Highlights

**A rare freeze at load is gone, and Faster text lookups says what keeps it off.** Two pull requests by
rodneypantonial.

## Fixes

- **Freeze at the loading screen** (#144): Night Lighting's `UpdateHooks` and the D3D9 hooks' registration lock were
  taken in opposite orders by the render thread (a Present-time setter) and the install thread (start-up), a deadlock
  of the #90 kind seen in kill dumps of hung 4.0.13 starts. `UpdateHooks` now takes the registration lock first, as
  PostScene does since #91, and keeps it while it unregisters.

## Performance

- **Faster text lookups names the mod that keeps it off** (#143): when another mod changed the text lookup, the table
  walk or the string tables' layout, the log names that mod by following the patch's jump into its module, with the
  setting to change for Sims 3 Performance Patch (`LocalizedStringCache`, `StblBucketLayoutTuning`) and Sims 3
  Modernization (`[Verify] Threads`). Setup 1.2.8 warns about the same causes, read only.

## Testing

`tools/string_table_index_test/run.ps1` and the Setup tests pass; the CPU smoke suite passes. In-game runner under the
RTX Remix bridge: the 4.0.14 build loads and plays with the tester's settings, and with Faster text lookups on it stands
down with "changed by Sims 3 Performance Patch (Sims3Performance.asi). To use Faster text lookups, set
LocalizedStringCache=0 in the [Patches] section of Sims3Performance.ini". The freeze is rare; #144 was shown with a
stress build that holds the locks (3 of 3 starts hung before, 3 of 3 loaded after).

## Known limitations

- The unregister path waits up to 1 s for the render thread while it holds the registration lock.
