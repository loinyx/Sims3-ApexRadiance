# Apex Radiance 1.4.0

Published 2026-09-29 · tag [`v1.4.0`](https://github.com/loinyx/Sims3-ApexRadiance/releases/tag/v1.4.0) · asset `ApexRadiance.asi`.

## Highlights

Even fewer stutters.

This release keeps going after the small stutters of The Sims 3, especially while the camera moves and when lots, Sims and textures load. The game still looks the same.

## New features

- **New experimental options (off by default):**
  - **Remember missing files:** skips the repeated searches for files that no package has.
  - **Faster file lists:** fewer stutters when Sims load outfits and shapes.
  - **Faster object lookups:** less work when lot lights update and for scripts.
- **Crash report:** if the game crashes, Apex Radiance writes `ApexRadiance_Crash.txt` in `Documents\Electronic Arts\The Sims 3\Apex Radiance\`. Please attach it when you report a problem.

## Changes

- **Wall shading waits while moving (on):** when a new lot comes into view, the shading of its walls used to be computed in one go, a hitch of 10 to 17 ms (more while lots load). Now it waits until the camera stops, and runs at most one step per frame.
- **Faster texture compression now uses several processor cores:** large textures are split across several cores, with the exact same result. A 2048×2048 texture drops from about 35 ms to about 6 ms.
- **Apex Radiance itself is lighter:** less work per frame in its graphics hooks and in Night Lights' lamp handling.
- Every performance option now shows an **Experimental** label: if anything looks wrong, turn that one off.

## Upgrade notes

Close the game, then replace `ApexRadiance.asi` in `The Sims 3\Game\Bin\`. Your settings are kept.
