# Apex Radiance 2.18.3

2026-10-30 · [v2.18.3](https://github.com/loinyx/Sims3-ApexRadiance/releases/tag/v2.18.3) · ApexRadiance.asi

## Highlights

**Hotfix: one light map per terrain chunk, wall shade across lot edges.** Each terrain chunk has two light maps: the
world file's, with the lamps as the world shipped, and the one the game rebuilds with the current lamps. Apex Radiance
took whichever map the last draw bound, so the ground light depended on draw order and changed with the camera angle.

## Changes

- **Light captures.** A light capture (F7) names the reason when a terrain draw is left to the game
  ([light-probe](../features/dev-tools/light-probe.md)).

## Fixes

- **Terrain light.** Every terrain shader variant draws the rebuilt map (current lamps), for lamp light and sun alpha
  alike, on the smoothed, plain, daylight, rain and multi-pass paths; the world file's map is no longer used once the
  rebuilt one exists. The smoothed chunk map is no longer rebuilt while the camera moves: about 54 rebuilds a second
  before, 0 now (recorded)
  ([world-atlas-and-smoothed-maps](../features/night-lighting/world-atlas-and-smoothed-maps.md#registration-recordworldchunk-render-thread-per-draw)).
- **Sidewalks.** Sidewalk pieces keep the light map mapping in a vertex shader constant Apex Radiance did not check; the
  constant it checked held whatever the previous draw left there, so a sidewalk was lit or dark from one view to the
  next. The mapping is now read only from constants the vertex shader actually reads.
- **Wall shade on the ground.** Outside a lot, the walls' shade from every lot nearby was averaged by lamp light; a lot
  next door that sees the lamp but not the wall lightened the shadow (measured beside a low wall: 0.12 just inside the
  lot, 0.55 just outside, a straight cut along the edge). The world grass now takes the largest light loss any lot
  computes there, so the shade matches the lot's own value at its edge; a wall two lots both know is not counted twice
  ([lot-light-pass](../features/night-lighting/lot-light-pass.md)).
- **Instant (GPU).** Neighbouring lots are picked only when the active lot has lamp posts. Before, a camera moving
  between lots without posts made their rooms solve again on every pick, and objects took seconds to show their light
  ([rt-outdoor-lamps](../features/night-lighting/rt-outdoor-lamps.md)).

## Known limitations

- Tested in game at night in the rain; dry weather and snow use the same code but were not checked in game for this
  release.
- Right after a world loads, the ground shows the lamps without the walls' shade for a few seconds, until each lot's
  shade is built.
