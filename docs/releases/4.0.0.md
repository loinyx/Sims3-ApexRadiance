# Apex Radiance 4.0.0

2026-11-14 · [v4.0.0](https://github.com/loinyx/Sims3-ApexRadiance/releases/tag/v4.0.0) · ApexRadianceSetup.exe, Apex-Radiance-4.0.0-Manual-install.zip

## Highlights

**ReShade looks inside Apex, and screenshots and videos with your effects.** A new Shaders page runs ReShade and GShade
presets (.ini) inside Apex, without either installed, and a new Capture page takes screenshots and records videos with
Apex's effects. The capture and the first ReShade looks were contributed by @ModestPixels.

## New features

- **Shaders** (Image > Shaders, tabs Look and Library). Pick a look (a ReShade or GShade .ini, one of five built-in looks,
  or one imported with Import), set its Strength and whether the interface stays without it (Interface without shaders, on by default), then switch,
  reorder and tune its shaders. 17 shaders are built in; the player's own .fx files go in the Shaders folder and are
  compiled by ReShade's own effect compiler; Get shader packs downloads the packs of ReShade's official list (45 packs)
  from their authors' GitHub repositories, with a checkbox per pack. Only shaders that run on the game's Direct3D 9
  are listed ([Looks](../features/looks.md)).
- **Every ReShade parameter kind** gets its control: switches, segmented choices or a list, a colour picker, vectors on
  one row, number fields, the author's groups (collapsible), tooltips and text; 1245 of 1245 shown uniforms in 131
  real .fx files get one. The look's `PreprocessorDefinitions` apply and are editable under Advanced > Quality
  settings; a change recompiles that shader in the background.
- **Capture** (Image > Capture, tabs Screenshots and Video). Screenshots (PNG or JPG, with or without the look, series,
  size, file names with tokens) and videos (MP4, crash-safe MP4 or MKV, H.264 or HEVC, 720p to 1440p, 24 to 60 fps,
  game sound, an on-screen timer, clip and size limits) with Apex's effects; keys F8 and Shift+F8
  ([Screenshots and video](../features/screenshots-and-video.md)).

## Changes

- **Presets** get a Capture part (opt-in) and a Shaders part. An exported ZIP carries the look's .ini and, when asked,
  the player's own .fx files; shaders from downloadable packs go as the pack's name, and importing a preset that needs
  packs offers them with "Download them now" checked ([Presets](../features/presets.md)).
- **Less work per frame for looks**: no state block save and restore (26 to 28 µs a frame), a shader at Strength 0
  skipped, a compile cache in `Shaders\.cache` (a large shader 17.8 s the first time, 16 ms after), and browsing the
  library compiles nothing. Pixel hashes of 418 test pictures are identical before and after.
- **Preset window**: its body scrolls on short screens while its buttons stay in view.
- **Shaders a look can't run** keep their place in the look's list, each with what is missing in amber and its own
  action (Download, Add .fx files… or a spinner while it works), and Download all under the list; Open the Shaders
  folder and Check again are in the card's ⋯ menu; downloading keeps the player on the Look tab
  ([Looks](../features/looks.md#menu)).
- **A shader that doubles an Apex effect** (MXAO with Ambient Occlusion, a DOF shader with Depth Blur, SMAA or FXAA with
  Edge Smoothing) says so in amber on its own row, with a button that turns Apex's off; a LUT on with the look gets the
  same kind of row in the look card.
- **Clearer menus**: the chosen option of every segmented control is dark violet with white text; Advanced shows what
  is chosen inside ("100% size", "MP4, H.264"); Capture drops its group labels, "File type" becomes "Format", the video
  Look moves into Advanced, and the reason a video can't record is the Video card's status line, in amber. Importing or
  saving a look reports in the floating change note.
- **GShade presets with renamed shader files** (MXAO in "MXAO 4.0.2 EX.fx") run the same technique from a pack file
  (`qUINT_mxao.fx`), with the look's own values; an exported preset names that pack.
- **Shaders is marked Beta** in the sidebar.

- **Apex Radiance Setup 1.1.5**: the download goes from 88 MB to 39 MB (only the Windows App SDK parts Setup uses, a
  trimmed .NET); the restart host (`ts3wrap.exe`) becomes an optional mod, Experimental and off by default, that sets
  `[ui] restart_host`; Apex starts it in the game's start folder so a relaunch reads the same `dxvk.conf`; a copied or
  moved game keeps its changes in its own folder ([Restart host](../features/performance/restart-host.md)).

## Fixes

- Pack downloads go on after a pack fails for lack of memory (the worker no longer stops for the session).
- The first check of downloaded packs no longer cuts the largest free block (offline, six packs: 794 MB left of 1202 MB
  before, 1154 MB after); background checks pause below 512 MB free ([Looks](../features/looks.md#performance-and-memory)).
- An effect switched off gives its GPU memory back after 120 frames; the scene depth is requested only while a shader
  that is on reads it.
- A preset whose shader file has the name of a different file of the player's fails the import with that name, instead
  of a numbered copy that never runs; own files are exported from where the scan finds them, pack files left out.
- Screenshots in a series or a second apart no longer get the same name; the video writer is closed under its lock.
- A preset's capture sound plays only from a local file and is not exported.
- With *Interface without shaders* on, the look covers the whole world again: it runs right after the game's bloom,
  before the interface and the game's colour pass, so the two squares at the top left without the look, the brighter
  tone and the look over part of the interface are gone, and the world matches the look with the interface included.
- MXAO and other depth shaders from packs no longer shade the whole picture and the sky: they read the game's depth
  the right way round, as ReShade players of this game set it.
- A look definition that its .fx overrides no longer compiles that file again at every scan.

## Known limitations

- Shaders that need features Direct3D 9 does not have (compute shaders, some texture formats) are hidden.
- Video recording needs Media Foundation (Windows N needs the Media Feature Pack) and is off while the game's own Edge
  Smoothing is on.

## Upgrade notes

- `[patches.GShadeLooks]` from development builds is read once and written as `[patches.Looks]`.
- Presets saved by development builds (3.3.0-dev) whose Color part carried the look are read with the look in the Shaders part.
