# Apex Radiance 1.2.0

Published 2026-09-29 · tag [`v1.2.0`](https://github.com/loinyx/Sims3-ApexRadiance/releases/tag/v1.2.0) · asset `ApexRadiance.asi`.

## Highlights

Support for other versions of the game (experimental).

Night Lights and Every-Story Ground Light no longer depend on fixed addresses of the Steam build. Apex Radiance now finds the game code it needs by itself when the game starts, so it can work on other Windows versions of The Sims 3:

## New features

| Version | Status |
|---|---|
| Steam 1.67.2 | Supported (unchanged, verified) |
| EA App 1.69.47 | **Experimental**, should work, testing in progress |
| Origin/EA 1.69.43, Disc 1.67.2 | Experimental, untested |
| Mac | Not supported (Windows only) |

## Known limitations

If something the lighting needs isn't found on your version, that feature just shows "Not available" in the menu with the reason, and nothing in the game is changed. Color filters, anti-aliasing, Depth Blur and the borderless window work on every Windows version.

## Upgrade notes

If you play on a non-Steam version, feedback is very welcome: please attach `Documents\Electronic Arts\The Sims 3\Apex Radiance\ApexRadiance_LOG.txt` to an issue.

Close the game, then replace `ApexRadiance.asi` in `The Sims 3\Game\Bin\`. Your settings are kept.
