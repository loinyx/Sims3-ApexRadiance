# Apex Radiance 2.11.0

Published 2026-10-07 · tag [`v2.11.0`](https://github.com/loinyx/Sims3-ApexRadiance/releases/tag/v2.11.0) · asset `ApexRadiance.asi`.

## Highlights

Color controls and hidden-interface effects.

## Changes

- **Color overview:** enable Basic, Tones, Color, Detail and Filters separately. The main Image switch disables them together while keeping your adjustments.
- **Filter shortcuts:** right-click a filter to assign your own on/off key combination. None are assigned by default; a small tag shows each assigned shortcut to the left of its expand arrow.
- **Cleaner filters:** compact groups, expandable adjustments and a shortcut dialog matching the menu.
- **Hidden interface:** corrected effect timing for the recorded F10 and hidden-photo rendering states, without changing effect or lighting formulas.
- **Ambient Occlusion:** removed Half resolution. AO runs at full resolution; this can increase GPU cost if you previously used that option.
- **What's new and languages:** refreshed the in-game version notes and translations. The README now lists all 21 supported menu languages.

## Known limitations

Hidden-interface rendering still uses a fallback before a visible frame teaches the scene-copy target. Visual parity across every scene and graphics backend remains unverified.

## Upgrade notes

Close the game, then replace `ApexRadiance.asi` in `The Sims 3\Game\Bin\`. Your settings are kept.
