# Apex Radiance 3.1.0

2026-11-10 · [v3.1.0](https://github.com/loinyx/Sims3-ApexRadiance/releases/tag/v3.1.0) · ApexRadiance.asi

## Highlights

**A steadier frame rate, a clearer Overview, and fences that stay dark behind walls.** The new Display page sets the
window mode, the resolution and an even frame-rate limit; the Overview shows the game's memory and gives each page one
switch; fences and garden edging behind a house no longer take the light of its lamps through the wall.

## New features

- **Display** (System > Display). Window, borderless or exclusive fullscreen, at the game's resolution or a mode of the
  graphics card; a frame-rate limit paced at the start of each frame, with a separate limit while another window is in
  front; an optional FPS counter in a corner of the screen. Changes apply while the game runs, through the game's own
  device-lost path ([display](../features/display.md)).
- **Overview.** One status card, the effects as rows with a switch per page that remembers what was on, a frame-rate
  card and a Game memory card (used and free in GB, Room to save's reserve shown apart). *Turn off Apex* keeps everything
  and *Turn Apex on* puts it back ([ui](../ui.md)).
- **Low memory note.** With the menu closed, a card asks to save when the game's largest free block gets low, again
  after 5 minutes while it stays low and at once when it becomes critical; Overview > Game memory turns it off
  ([memory budget](../features/memory-budget.md)).
- **Update card.** After an update, the first menu shows one small card with the version's headline; *What's new* opens
  the changelog on it ([ui](../ui.md#whats-new)).

## Changes

- **What's new.** A version's headline replaces its counts, the newest opens on its highlights, and the full list is
  folded by area with a New, Better or Fix tag on each line. The 3.0.0 notes are rewritten in 13 lines.
- **RTX Remix bridge.** Settings > Compatibility has a folded guide to install or remove it, with Download and Open
  Game\Bin; under the bridge, a card offers to turn off uncompressed lot and Sim textures that make the camera stutter,
  editing that mod's settings file with a backup after the click ([rtx-remix-bridge](../features/rtx-remix-bridge.md)).
- **Custom frame-rate slider.** The track lines up with the select above it, with the value on its left.

## Fixes

- **Fences behind a wall.** A fence group whose lamp list keeps a lamp that a wall hides from some pieces is drawn in
  runs, each without the lamps its pieces cannot see; garden edging set in a house's wall no longer takes the house's
  lamps ([fences](../features/night-lighting/fences.md)).
- **Exclusive fullscreen under the RTX Remix bridge.** It hung the game at the Reset; under the bridge, Fullscreen runs
  as Borderless.

## Known limitations

- Display: live mode switches with the game focused, exclusive fullscreen and Alt+Tab, in-process DXVK and plain
  Direct3D 9 are not yet tested in game ([validation](../validation/display.md)).
- A fence piece set in a wall is tested beyond the wall only for walls along x or z.
- The RTX Remix bridge on the EA app still needs `client.targetProcess = TS3.exe` set by hand in both `bridge.conf` files.
