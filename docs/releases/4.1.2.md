# Apex Radiance 4.1.2

Released 2026-11-26 · ApexLauncher.exe (also attached as ApexRadianceSetup.exe for older Setups' update), Apex-Radiance-4.1.2-Manual-install.zip

## Highlights

**Apex Launcher 2.3.1.** A Load order page that shows which mod the game reads first, a health card on Home with the
crystal and the first thing to look at, and scrapbook frames drawn anew. The mod itself is the same as 4.1.1.

## Changes

- **Load order** ([load-order-and-conflicts.md](../features/launcher/load-order-and-conflicts.md)): a page in the Mods
  tools lists the mods that are on in the order `Resource.cfg` makes the game read them, grouped by priority, with
  *Wins over* and *Loses to* on mods that change the same thing and a way to their conflicts.
- **Home** ([home-and-play.md](../features/launcher/home-and-play.md)): the game's state sits in a low glass card over
  the picture, the crystal beside it in a soft light; the whole card opens Health.
- **Automatic backups of a save** ([saves-and-backups.md](../features/launcher/saves-and-backups.md)): the same as every
  save or its own times and number to keep, chosen from one list as in the install's last step.
- **Scrapbook** ([gallery.md](../features/launcher/gallery.md)): frames drawn anew, with Walnut, Gallery and Neon added
  and Paper clip taken out; the picker shows each frame on the album's own board. Tape takes the board's hue. The default
  board is white on the light theme. A caption is written in place, wrapping into its two lines.
- **Credits** in Settings take the colours of the theme in use after a change between light and dark.
- **Documentation:** a page for each area of the launcher ([launcher](../features/launcher/README.md)) and a design
  system skill for new screens.

## Fixes

- Opening a picture in the Gallery no longer closes the launcher when Windows refuses its opening animation.
- A video's thumbnail no longer fails for a large size.
