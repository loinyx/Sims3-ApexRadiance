# Apex Radiance 3.1.6

2026-11-12 · [v3.1.6](https://github.com/loinyx/Sims3-ApexRadiance/releases/tag/v3.1.6) · ApexRadianceSetup.exe, Apex-Radiance-3.1.6-Manual-install.zip

## Highlights

**Two downloads: the installer, or one zip to install by hand.** The release page now has just
`ApexRadianceSetup.exe` and `Apex-Radiance-3.1.6-Manual-install.zip`, and the RTX Remix bridge is no longer marked
experimental. The mod itself is the same as 3.1.5.

## Changes

- **Downloads.** `Apex-Radiance-3.1.6-Manual-install.zip` holds one folder with `How to install.txt`,
  `ApexRadiance.asi`, `ts3wrap.exe` and `RTX Remix bridge\` (the bridge, `.trex` included). `ApexRadiance.asi` and
  `Apex-Radiance-RTX-Remix-bridge.zip` are no longer files of their own.
- **Apex Radiance Setup 1.1.2** installs Apex Radiance, the restart host and the RTX Remix bridge from that zip, and no
  longer calls the bridge experimental ([Apex Radiance Setup](../features/installer.md)).
- **RTX Remix bridge** is no longer marked experimental in Setup, the guides and the README.

## Known limitations

- Setups before 1.1.2 look for loose files and cannot install from this release: download the new
  `ApexRadianceSetup.exe` once (Setup 1.1.0 and 1.1.1 offer it on their start page).
