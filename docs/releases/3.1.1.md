# Apex Radiance 3.1.1

2026-11-11 · [v3.1.1](https://github.com/loinyx/Sims3-ApexRadiance/releases/tag/v3.1.1) · ApexRadiance.asi, Apex-Radiance-RTX-Remix-bridge.zip, ApexRadianceSetup.exe

## Highlights

**Better compatibility with the RTX Remix bridge.** Under the bridge, small parts of the picture no longer blink on a
still lot and the sea keeps its reflection. Display's Resolution now changes the game's own resolution, on Steam and the
EA app.

## New features

- **Apex Radiance Setup.** `ApexRadianceSetup.exe`, attached to the release, installs, updates, repairs and removes Apex
  Radiance and the mods it works with, keeping a backup of every file it replaces. It is the recommended way to install;
  the manual install still works ([installer](../features/installer.md)).

## Changes

- **Lighting.** General lighting improvements for better RTX Remix compatibility.
- **Resolution.** Display > Resolution changes the game's own resolution: the picture fills the screen instead of the
  top-left corner, the game saves it in `Options.ini`, and it works on EA app 1.69, where the game stayed at 1024x768,
  stretched. A size below 1024x768 is scaled to the window ([display](../features/display.md)).
- **New Game.** Lots the game lights only for their household pictures skip light sharing; the played lot is still lit
  in full (`fastLotPictures`, TOML only, default on)
  ([level light share](../features/night-lighting/level-light-share.md)).
- **Bug reports.** Capture folders include the bridge and DXVK logs (the last 8 MB of each), recordings under the
  bridge add a frame trace, and crash dumps include memory region information
  ([bug reports](../features/bug-reports.md)).
- **Overview.** A thin line separates frame rate and game memory when the status card's tiles are stacked.
- **RTX Remix bridge download.** The bridge zip carries its licence notes in its install text and has its own Nexus
  file ([rtx-remix-bridge](../features/rtx-remix-bridge.md)).

## Fixes

- **Blinking under the bridge.** Small parts of the picture no longer blink while the lot is left still
  ([rtx-remix-bridge](../features/rtx-remix-bridge.md)).
- **The sea under the bridge.** It no longer loses its reflection for a frame.
- **Loading screens under the bridge.** They no longer lose their top-right quarter to black.
- **Exclusive fullscreen under the bridge.** The game's own exclusive fullscreen, with Display on Game and no
  `Options.ini`, no longer hangs; it runs as Borderless ([display](../features/display.md)).
- **The game's launcher.** Starting the game through `Sims3Launcher.exe` no longer crashes the launcher in the
  background; Apex stays idle outside the game, on every game version.
- **Crash shortly after the active lot changes.** On Steam 1.67, a room could follow a gone neighbour lot's pointers
  and call a game object as its reflection cube, crashing in `ArchAmbientConsts`; such an object is refused now.
  Contribution by @rodneypantonial (#63, fixes #62) ([arches](../features/night-lighting/arches.md)).
- **Delegate check crash.** The game's own check of delegates with no parameters crashed the simulation; an always-on
  game fix corrects it ([delegate signature fix](../features/delegate-signature-fix.md)).
- **New Game loading.** A New Game on a big lot no longer stays on its loading screen indefinitely.

## Known limitations

- The three bridge fixes above (blinking parts, the sea's reflection, the loading-screen quarter: bridge patches 0011
  to 0013) are not yet confirmed in game ([validation](../validation/rtx-remix-bridge.md#open-checks)).
- On the EA app, picture lots skipping light sharing is not yet confirmed in game, and the New Game time it saves is
  not measured on any version ([validation](../validation/night-lighting-level-light-share.md#open-checks)).
- The RTX Remix bridge on the EA app still needs `client.targetProcess = TS3.exe` set by hand in both `bridge.conf`
  files when installed manually; Apex Radiance Setup sets it.

## Upgrade notes

- The bridge fixes are in the bridge itself: players of the RTX Remix bridge replace its files from
  `Apex-Radiance-RTX-Remix-bridge.zip` as well as `ApexRadiance.asi`. Settings are kept.
