# Apex Radiance 2.1.0

Published 2026-09-30 · tag [`v2.1.0`](https://github.com/loinyx/Sims3-ApexRadiance/releases/tag/v2.1.0) · asset `ApexRadiance.asi`.

## Highlights

Ambient Occlusion (experimental) and a start note on the first loading screen.

## New features

- **Ambient Occlusion (Experimental):** soft shade where things meet, under furniture, in corners, where walls meet the floor and around houses and trees. It is computed at full resolution with no noise, so it stays perfectly still when the camera does, and lamp-lit or bright surfaces keep their light and color instead of turning grey. Find it in the new Ambient Occlusion page: Strength, and under Advanced, Reach, Keep lamp light and Quality. It needs the game's own Edge Smoothing off, and is part of profiles and of Compare with the game.
- **Start note:** a small note in the top-left corner shows that Apex Radiance is running and which key opens the menu, from the game's first loading screen, every time you start the game.

## Fixes

- **After loading:** the automatic lighting refresh no longer runs at the main menu before a save is loaded.

## Upgrade notes

Close the game, then replace `ApexRadiance.asi` in `The Sims 3\Game\Bin\`. Your settings are kept.
